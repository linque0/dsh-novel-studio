# 设定与人物

## 顺序

1. `studio_search` 按名字/关键词找既有条目，先读现状。
2. `studio_read {kind:'character'|'lore'}` 读全文，注意别名与适用范围。
3. 要改设定：`studio_propose {kind:'setting.update'}` 交候选，作者确认后 `studio_apply`。

## 原则

- 人物档案是**作者设定**，不等同于正文里已经发生的事实；两者冲突时以正文与作者当前说明为准。
- 关系与能力必须有依据；没有依据就标为待定，不擅自新增身份、亲属或力量上限。
- 改动会波及已写章节时，明确说明影响范围，让作者决定是否回改。
