# 作品库接手

## 先确认目标

- 用 studio_works 的 op=list 看书目；op=open 打开目标作品，拿到卷与章节目录。
- 作者没有指定作品时，用最近更新的那部，但要说明你打开了哪一部。
- 不同会话各自独立：不要替别的会话切书，也不要假设作者正在看哪一章。

## 读到足够再写

- 先看目录与字数（studio_outline），再按游标分页读正文（studio_read）。
- 目录标题和摘要不能代替正文；没有读过的章节不要声称读过。
- 人物与设定是作者的创作约束，不等于正文里已经发生的事实；两者冲突时以正文与作者当前说明为准。
- 需要多章资料时逐章按需读取，不要一次索取整本书。

## 边界

- 规划是意图，正文是事实。
- 讨论提案不等于作者采用；未确认的设想不得写成既定事实。
- 写操作只能产出提案，由作者在界面里确认；不要声称已保存。
