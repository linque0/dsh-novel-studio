# 剧情讨论与方案

## 顺序

1. `studio_works`/`studio_outline` 明确范围（哪一章、哪条线）。
2. `studio_search` 找相关伏笔与既有设定，别凭空新增世界规则。
3. 给方案时写清：谁想要什么、什么阻碍、什么选择改变局面、退出时留下什么状态。
4. 分支要真有差异，不是同一件事换三种说法。

## 边界

- 方案不等于已发生；作者未采纳的设想不得写成既定事实。
- 简单情节不必强行画成复杂网络；不确定的地方标成待决，而不是补设定。
- 需要落库的结构性内容走 `studio_propose`，且必须作者确认。
