# 定向修订

## 顺序

1. `studio_read` 读源稿全文（改稿要整章上下文，不只看选段）。
2. 只处理作者点选的问题；未选意见不构成改稿任务。
3. 每条改动要能回答：依据在哪、改后解决了什么。
4. `studio_propose {kind:'chapter.replace'}` 交完整候选 → 作者确认 → `studio_apply`。

## 原则

- 选最小改动；未受影响的情节、声线、叙述距离保持原样。
- 不靠新增设定去圆一个疑点；证据不足就保留不确定并说明。
- 改完用 `studio_recheck` 复核原问题，别自称"已全部解决"。
