## 附：v8.1 修掉的一处真实 bug

封面文字发暗不是颜色问题，是**层级问题**：玻璃里的压暗层用的是 `.glass::after`，
伪元素排在所有子元素之后绘制，等于给文字盖了一层灰纱。

修法：画面 `z-index:0` → 压暗/柔光 `z-index:1` → 所有文字 `z-index:2`。
改完书名是真正的纯白（截图 `01-shelf.png`，局部见发布说明）。

## 附：v8.2 修掉封面压字（横排书名 × 左侧竖排拉丁）

**现象**：书名含拉丁字母或超过 6 字时走横排分支（`.is-wide`），而它与左侧竖排拉丁小字
（`.ls-glyph-latin`）共用同一条左边线 `left:16px` —— 书名整段压在拉丁上，拉丁只能从笔画缝隙
和两行之间透出来，「画布验证书A」即此形。横排分支另有第二处隐患：`bottom:auto` 让它向下自由
生长，且 560–899 档仍继承 26px（168 卡只有 100px 行宽、3 字/行），10 字以上书名会压到
「朱记 + 作者」脚注行。

**修法**（`app/src/styles/skins/latent-shelf.css`）：

| 项 | 值 |
|---|---|
| 横排书名让开拉丁列 | `left:16 → 32`（≥560，= 16 边距 + 7.5 列宽 + 8.5 气口）/ `11 → 26`（≤559） |
| 拉丁列宽锁定 | `line-height:1`，列宽即字号，让位量可算（竖排步进不受影响） |
| 横排书名底部硬边界 | `bottom: auto → 52 / 52 / 30`，长书名宁可整段裁也不压脚注 |
| 横排长书名档 | 新 `.is-wide.is-long`（> 8 字）：≥900 22px / 560–899 18px / ≤559 12px |
| 560–899 横排补降档 | 22px（原来继承 26px）；长档 18px |
| 顶部题材/状态 | `gap:10px` + 逐枚省略，长题材不再顶到状态上 |

**判据**（`scripts/verify-app.mjs`，380 / 760 / 1280 三档各跑一遍）：封面文字互不遮挡 /
封面文字不出玻璃 / 书名不被裁切。种子补成三本书：竖排（雾港纪年）、横排含拉丁（画布验证书A）、
横排长书名（雾港纪年之外的第七夜）。

**取证**：修前「封面文字互不遮挡」三档全红（书名×拉丁 叠 8–10px × 14–53px，760 档另有长书名被裁 2px）；
修后 209/209 全绿，截图在 `.tmp-verify-app/`。

## 附：2026-11 筛选药丸上移

- 「全部 · N / N」药丸在两个窄档会压住聚焦卡的上沿：行高比卡片矮（560–899 行 282 < 卡 288、≤559 行 216 < 卡 228），
  卡片在行内垂直居中，顶边就被抬到行顶之上，正好撞进药丸底边。
- 修法（只动数值）：`560–899` 行高 282→**304**、药丸 `top` 18→**8**；`≤559` 行高 216→**236**、药丸 `top` 8→**2**。
  实测药丸底与卡顶间隙：380 = 6px、760 = 7px、1280 = 14px。
- 判据：`书架筛选药丸不压卡片`（药丸 rect.bottom ≤ 聚焦卡 rect.top − 2），三档书架 run 各出一条。
