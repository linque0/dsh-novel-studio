# 隐现书架 · 动效与时序（v4，GPU）

## 背景（GPU 每帧）

| # | 元素 | 参数 |
|---|---|---|
| 1 | 控制点游走 | 5 个点，周期 20–40s，彼此相位错开 |
| 2 | 域扭曲 | 两级，振幅 0.020 / 0.010，频率 5.7 / 11.3 |
| 3 | 速度 | 基础 0.09，交互脉冲时最高 +0.22（240ms 上升、×0.985 衰减） |
| 4 | 换书配色 | 300ms 三色插值（GPU 侧 `setPalette` 内部完成） |
| 5 | 像素层 | 64×64 蓝噪声平铺 + 6 级量化，按 `uPixel` 混合 |
| 6 | 暗角 / 颗粒 | `0.26 + 0.74·vig`；每帧 ±0.022 |
| 7 | 自适应分辨率 | 60 帧均值 > 22ms 降档，< 12ms 升档；档位 1.5 / 1.25 / 1 / 0.75，上限 1600px |
