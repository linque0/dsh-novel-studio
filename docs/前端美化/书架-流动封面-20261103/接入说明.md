# 接入说明（插件版落点）

设计稿只到「书架首屏」为止，落地时的去向如下。

## 代码落点

| 层 | 路径 | 说明 |
|---|---|---|
| 渲染器 | `app/src/services/latent/latent-gl.js` | 移植的 `createLatentBackdrop`（WebGL2/GLSL 100 双通道）+ `createCoverPainter`（**单上下文**画所有封面） |
| 蓝噪声 | `app/src/services/latent/blue-noise.js` | 64×64 原始字节 base64，与设计稿逐字节相同 |
| 配色 | `app/src/services/latent/palette.js` | `CLOTH`/`ACCENTS` + `paletteOf(work)`；accent 取 `hashString(work.id)` |
| CPU 兜底 | `app/src/services/latent/cpu-backdrop.js` | Bayer + 域扭曲，与 GPU 版同签名 |
| 书架组件 | `app/src/components/LatentShelf.vue` | 背板/卡位/聚焦区/dock/空态 |
| 书架样式 | `app/src/styles/skins/latent-shelf.css` | 设计稿 `index.html:8-111` 的 `.latent-shelf` 命名空间版本 |
| 外壳语言 | `app/plugin/dsh/language.css` | `--nsx-*` 令牌 + 胶囊顶栏 + 弹层玻璃，只在 `body[data-skin='dsh']` 下生效 |

## 与设计稿的实现差异（有意为之）

1. **配色不跟列表下标**：设计稿按 `BOOKS.indexOf(book)` 取 accent，真实作品库会排序/筛选，改用 `hashString(work.id)`，同一本书永远同一套色。
2. **封面不逐张新建 WebGL 上下文**：设计稿的 `paintCoverArt()` 每次调用建一个上下文，12 本书会撞浏览器上限；改为单例 `createCoverPainter()`，全站上下文 ≤2（验收断言）。
3. **尺寸取画布自身**：设计稿按 `window.innerWidth/Height` 定尺寸，插件面板不是整窗，改为 `canvas.clientWidth/Height` + 父容器 `ResizeObserver`，取不到才回退 window。
4. **模块入口不是占位态**：设计稿点「正文/大纲/…」显示大字占位；插件版沿用既有语义——打开当前聚焦作品的对应模块，无作品时禁用。
5. **CPU 兜底修了设计稿一个真 bug**：设计稿 resize 后仍往旧的 `ImageData` 里画，现在每帧重取 `frameData.data`（三档栏宽会真的触发 resize）。

## 复跑

```bash
npm run build:app                 # app/ → assets/app
npm run verify:app                # 真 Chrome：380/760/1280 × 书架/正文，断言见脚本头部注释
node scripts/preview.mjs --serve  # 本地复现台（插件自己的静态路由 + RPC），浏览器里手动看
```

设计稿自身的复跑脚本（`tools/build-folia-page.mjs`、`tools/folia-design-capture.mjs`）只针对本目录的 `index.html`，不参与插件验收。
