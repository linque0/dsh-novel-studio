# 小说工坊 · 灵感融合总稿

直接打开 [交互原型](index.html)。也可从 [手札](index.html?view=journal) 或 [拼板](index.html?view=board) 开始。两种视图共用数据、搜索、标签与选中片段，各自记住滚动。左栏沿用 B 的开放式目录，C 不进入总稿。

本稿为独立演示原型。沿用上一轮 12 条《雾港纪年》片段和关联目标；保存只使用此原型专有的 `latent-inspiration-fusion-v1` 键，不访问正式插件数据库或真实作品。新建、编辑和转换会改变这份演示数据，刷新后可以继续。

## 已完成的交互

| 路径 | 可以实际操作的内容 |
|---|---|
| 手札／拼板 | 顶部切换、方向键切换、Alt+1／2；保留筛选与选中项，分别恢复滚动；未保存修改继续保留在编辑面板 |
| 记录 | 手札置顶输入、顶部弹窗、拼板分组添加；首行作为标题，Ctrl／Cmd+Enter 记录；空白输入提示，组合输入期间不触发记录 |
| 查找 | 搜索标题、正文、标签及关联名称；全部／未标记／有关联；单标签筛选、清除筛选、最新／最早／手动排序 |
| 修改 | 编辑标题与正文、显式保存修改；未提交输入作为草稿保存，关闭面板或刷新后可以继续修改；Ctrl／Cmd+S 保存 |
| 标签 | 添加已有或新标签、去重、移除；左栏计数与拼板分组同步；筛选结果变化后选择有效片段 |
| 拼板整理 | 手柄拖动、更多菜单上移／下移；跨主题组拖动前确认添加标签，保留原标签；拖到“未标记”不会静默清空标签 |
| 关联 | 查看已有目标正文、添加关联、移除关联；目标按 ID 区分，不按同名标题猜测；目标预览用安全文本显示 |
| 转换 | 选择位置，创建演示章节或设定目标，生成关联并打开结果预览；原灵感与原正文保留；结果及关联刷新后仍可读取 |
| 回收站 | 删除后可撤销；回收站浏览与恢复；回收站片段保留 ID、标签和关联，隐藏编辑入口 |
| 保存异常 | 写入失败不移除内存记录，显示待保存与重试；重试只保存当前状态，不重复新建；读取失败保留未完成输入并阻止覆盖原数据 |
| 键盘与窗口 | Esc 关闭当前弹窗并归还焦点、Ctrl／Cmd+K 搜索、快捷键说明、顶栏固定／自动隐藏；手机目录抽屉及详情底部面板 |

## 建议体验

1. 在手札写两行，按 Ctrl+Enter。选中新片段，添加「潮汐」标签，再切换拼板；正文与标签保留，左栏计数同步。
2. 点《退潮时，钟声从海底传来》，编辑一段正文。切换手札与拼板，继续原来的修改并保存；再刷新查看结果。
3. 在拼板用手柄把片段移到「人物」。确认增加标签，回到「场景」，同一片段仍在；也可以从更多菜单调整先后顺序。
4. 选择「转为章节」，换一个分卷，创建后查看正文。关闭预览，原灵感仍在，详情多出一条关联。
5. 删除一条灵感，点提示中的「撤销」；或从左栏进入回收站恢复。原 ID 和关联不变。
6. 380px 窗口中打开目录、选未标记、点卡片；详情从底部打开，Esc 或关闭返回原来的位置。

## 视觉与空间

沿用暗紫玻璃、玫瑰颗粒、宋体层级和薄荷色交互。字体与底图沿用三版探索稿，没有新添装饰插画或统计图。顶栏与页头保持紧凑；版面按实际顶栏高度伸缩。

手札保留连续段落与日期分组；拼板让场景、人物与对白并置，未标记和其他标签同样可到达，不隐藏内容。桌面拼板可横向浏览更多分组，打开详情后保留分组位置。手机改为分组切换与单列卡片，避免把文字压成窄列。

左栏采用 B 的开放式排版，不套第二层玻璃卡。详情为单一纵向滚动，普通三段正文不再嵌入第二个滚动框。长标签截断时仍保留完整可访问名称；移除、编辑和关闭入口在手机上扩大点击范围。

## 动效

- 首次进入为 5px、约 360ms 的短出场，内容立即可操作。
- 视图指示底板约 190ms 平移；切换后的内容为 4px、180ms 轻过渡，快速操作以最新状态为准。
- 详情从右侧或手机底部展开；选择、按钮按下、标签与操作结果即时反馈。
- 系统减少动态效果时直接显示终态。手机软键盘仅改变可用高度时不重建输入框，保留焦点与选区。

## 原型边界与复跑

这是灵感模块的独立交互设计。转换目标有实际演示内容及位置，并可预览；没有同时重建正文、设定等其他模块的完整编辑器。顶栏的其他模块名称作为既有外壳展示，不跳转正式作品。正式落地仍应复用既有内容、双链格式及保存链路。

在本目录执行：`node --test tools/model.test.mjs`、`node tools/verify.mjs`。浏览器验证使用临时配置与演示原型存储，不访问正在使用的浏览器。文件职责和实现清单在 [PLAN.md](PLAN.md)。
