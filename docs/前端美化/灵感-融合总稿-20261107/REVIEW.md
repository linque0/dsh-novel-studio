# 独立视觉复核记录

范围：既有 A／B 规范上的融合设计，1440、864、380px 两视图及详情；不读代码，不打分。

首轮提出：

1. 手札正文与图标显得比拼板偏淡。定位为截图未等待首次入场动画结束；截图改为等待有限动画终态，同时稍提高编辑与关联移除图标的可辨认性。
2. 桌面详情存在正文与整栏双层滚动。移除正文内部的最大高度与独立滚动，统一整栏浏览。
