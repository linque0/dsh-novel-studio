## 与设计稿仍存差异（有意保留）

1. **视图切换器**：设计稿头部的「条目编写／设定详情／视觉导图」三段，等 B/C 落地再加，避免出现点了没用的控件。
2. **工具条按钮**：设计稿只画了撤销/重做、B I U、同级/子级；插件版保留了 S、字体色、底色、清除、导入（删按钮等于删功能）。
3. **"全部设定"开关**：按你定的「以节点化树为主体」，主区永远是整棵森林，没有模式切换，故不需要该入口。
4. **行尾操作**：设计稿在选中行常显「∞ 6 / 展开 / 容器 / ⋯」，插件版沿用 hover 才显形。
