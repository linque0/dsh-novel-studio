## 二、契约

### 1. 引擎签名

```js
import { mountFlowBackdrop } from '../services/latent/flow.js'

const api = mountFlowBackdrop(canvas, {
  palette,        // { a:[r,g,b] 0~1, b:[…], c:[…] }；传 null 用引擎默认色
  reducedMotion,  // Boolean，对应 prefers-reduced-motion
  simWidth,       // CPU 兜底的模拟分辨率（<560:320 / <900:480 / 其余 640）
  maxEdge,        // GPU 画布长边上限（<900:1280 / 其余 1600）
  onFallback      // (reason) => void，'gpu-unavailable' | 'context-lost' | 着色器错误
})

api.backend                       // 'gpu' | 'cpu'（getter，随降级变化）
api.setPalette(palette, {duration, seed})
api.pulse(strength)               // 打字涟漪
api.setReducedMotion(bool)
api.setPixelMix(value)
api.resize()
api.stats()                       // { backend, renderer, avgFrameMs, scale, pixels:[w,h], time }
api.dispose()
```

`stats()` 至少给契约里的六个字段（引擎另带 `noise`，判据不读它）。

### 2. 两个必须保留的坑

1. **CPU 兜底前必须换一张新画布**：碰过 WebGL 的画布在 `loseContext()` 之后取不回可用的 2D 上下文，
   所以降级路径是 `document.createElement('canvas')` → 抄类名 → `replaceWith` → 在新画布上建 CPU 底。
   调用方的 `ref` 指向的元素在 `replaceWith` 之后已脱流，新画布记在它身上（`__nsFlowLive`），下次挂载顺着找回。
2. **`webglcontextlost` 走 `onFallback`**：由引擎接手（先换画布接 CPU 底，再通知调用方），
   调用方不做任何 canvas 侧处理，只负责 UI 层可选的提示。

### 3. DOM 契约

主窗口与拆窗面板同构（书架保持自己那套）：

```html
<div class="st-backdrop-wrap">
  <canvas class="st-backdrop"></canvas>
  <div class="st-layer dots"></div>
  <div class="st-layer vignette"></div>
  <div class="st-layer grain"></div>
</div>
```

- 书架仍是 `.latent-shelf .ls-backdrop-wrap > canvas.ls-backdrop`，本次不动（`latent-shelf.css` 不进改动）。
- 层级：背景 `z-index:0` < 内容层 `.wb-body / .panel-body` `z-index:1` < 顶栏 `z-index:40`。

### 4. 外壳标记

`.workbench-shell[data-flow="on"]` 与 `.panel-host[data-flow="on"]`。
`flow-shell.css` 的所有规则都以 `html body[data-skin='dsh'] :is(.workbench-shell, .panel-host)[data-flow] …` 起头 (0,4,x)：
既高过 `dsh.css` 的 (0,3,1)，也高过 `latent-studio.css` 材质表的 (0,3,2)，覆盖关系不随打包顺序漂移。
没有 `data-flow` 的窗口（设置窗、预设窗等）观感一律不变。

### 5. 全局钩子

| 钩子 | 存在于 | 用途 |
|---|---|---|
| `window.__nsFlowBackdrop()` | 书架 / 工作台 / 拆窗面板 | 统一入口，返回 `stats()` |
| `window.__nsStudioBackdrop()` | 工作台 / 拆窗面板 | 旧名保留（旧验收脚本读它），与上者是同一个函数 |
| `window.__nsLatentStats()` | 书架 | 旧名保留，与上者是同一个函数 |

三者指向同一个 `stats()` 包装；当前壳层卸载时只撤自己那面旗，交给接手的壳层。
验收脚本的读取顺序是 `__nsFlowBackdrop` → `__nsStudioBackdrop`。

### 6. 作色实参

`paletteOf(work)`（`palette.js:46`）；`seed = (hashString(work.id) % 997) / 997`；`duration: 600`。
无作品时传 `palette: null`，引擎用 `DEFAULT_PALETTE`（`latent-gl.js:299`）。
书架换封面用 300ms，正文页与面板换作品用 600ms —— 书架是在一屏里换装，后两者是整页底色，快切会闪。

### 7. 玻璃实参

| 目标 | 背景 | 圆角 | 模糊 |
|---|---|---|---|
| `.side-panel` / `.right-panel`（侧栏、批注栏） | `color-mix(in srgb, var(--ns-layer-1, #232324) 62%, transparent)` | 20px | `blur(20px) saturate(1.5)` |
| `.center-pane`（主区） | `color-mix(in srgb, var(--ns-layer-1, #232324) 52%, transparent)` | 20px | `blur(20px) saturate(1.5)` |

`--ns-layer-1` 缺失时回退 `#232324`（深色令牌）。侧栏原本的 `--ls-glass-fill` 渐变必须 `background-image: none` 掉，
否则 62% 又被拉回实底。验收判的是「`alpha <= 0.75` 且 `backdrop-filter` 含 `blur`」，不按具体色值判。
