# 正文 · 伏案 · 动效与时序

> 设计稿 `index.html` 的动效口径。**背景（1–6）走 WebGL，界面（7–14）走 CSS**，两套互不耦合；`prefers-reduced-motion` 对两者同时生效。

## 一、背景：静水（ink，默认）

| # | 元素 | 参数 |
|---|---|---|
| 1 | 墨团对流 | 4 octave fbm，极慢对流 `flow = 0.015`；三层 `1/d^2.2` 墨团，色板压到 12–18% alpha（`#1b2430` / `#22262b` / `#4a2a24`） |
| 2 | 呼吸 | 域扭曲振幅 `0.006`、周期 24s、相位随机 |
| 3 | 像素层 | 64×64 蓝噪声（逐字节同书架稿），6 级量化作用于 alpha，`pixel = 0.35` |
| 4 | 暗角 / 颗粒 | 暗角 `0.34`；颗粒 `0.03`（界面层另有 `.st-layer.grain` 0.05 静态颗粒） |
| 5 | 打字涟漪 | `pulse(0.05)` → `amp += 0.05`（上限 0.12），以画布中心为圆心、半径 220px 的光斑，τ ≈ 0.35s 指数衰减，**1.4s 硬归零** |
| 6 | 自适应分辨率 | 档位 1.5 / 1.25 / 1 / 0.75，上限 1600px；60 帧均值 > 22ms 降档、< 12ms 升档（实测 5.55–5.65ms，停在 1.5 档） |

**另两个方向**（同骨架，只换流体层）：`lamp` 灯池 `#2a1f18 → #08090c`（中心 uv y = 0.18，椭圆 .62/.42）+ 200 粒 1px 尘埃（上行 0.4 px/s，sin 微抖）；`ridge` 底部四层 1D 噪声山线视差 0.3 / 0.6 / 0.9 / 1.2 px/s + `#07090d` 近平面 + 月晕。

## 二、界面

| # | 触发 | 变化 | 时长 / 曲线 |
|---|---|---|---|
| 7 | 切章 | 稿纸 `.is-swapping` 淡出 → 重建段落 → 淡入；眉标随渲染落位 | 120ms 出 / 220ms 入，`--st-ease` |
| 8 | 切章 | 背景色板插值 `setPalette({a,b,c},{duration:300})` | 300ms |
| 9 | 打字 | 涟漪（见 #5），`input` 事件**节流 80ms**，打字越快越亮但不累积 | 衰减见 #5 |
| 10 | 保存点 | `saved → saving`：朱记点脉冲 `st-pulse` 1.2s 循环；`saving → saved` 600ms 后转白 40% + 时戳 | 600ms |
| 11 | 字数目标 | `.goal-track i` 宽度 | 480ms `--st-ease` |
| 12 | 浮层 | `.st-pop` 打开：上移 6px + scale(.98→1) + 淡入；`.st-scrim` 淡入 | 200ms |
| 13 | 抽屉 | 窄栏章节 / 批注抽屉平移进出 | 380ms `--st-ease` |
| 14 | 悬停 | 章节行 / 工具按钮 / 胶囊按钮：底色提亮；胶囊另抬 1px | 160–180ms |

## 三、降级

| 条件 | 行为 |
|---|---|
| `prefers-reduced-motion: reduce` | `u_time` 冻结（两次采样 `time` 相同，实测 timeA = timeB = 0）；全部 CSS 过渡降到 1ms |
| 取不到 WebGL / `?gpu=0` | `createStudioBackdrop` 返回 `backend:'css'` 的空操作 api；`html[data-bg-fallback='1']` 用三段径向渐变静态兜底；不报错、不 console.error |
| 画面尺寸变化 | `ResizeObserver` 取画布自身 clientWidth/Height，取不到才回退 window（书架稿的 window 口径在此修正） |
