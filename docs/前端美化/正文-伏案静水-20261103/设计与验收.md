## 附：2026-11 六改 · 「更多格式」弹层不破底线 + 去重 + 插件版取消纸面切换

### 一、突破底线：弹层没有高度上限

- **症状**：小窗口（用户截图 655×749）展开「更多格式」，弹层从工具栏一直垂到屏幕外。
- **根因**：`.tb-more` 是 `flex-direction: column` 的单列，16 行 × 30px + 2 条分隔 ≈ **750px**；
  而 naive 的 `.n-popover` 在本仓 **零覆写、没有任何 max-height**（`grep -n max-height latent-studio.css` 只有 4 处 `none`）。
  条目越多越长，与视口高度无关。
- **改法（§45）**：`.tb-more` 由单列改网格 `repeat(auto-fit, minmax(84px, 1fr))`，
  并给出 `max-height: min(70vh, 420px); overflow-y: auto; overscroll-behavior: contain`；
  分隔线 / 章节状态栏 / 内嵌的二级触发器一律 `grid-column: 1 / -1` 通栏。
  另补一层与人无关的兜底：`.v-binder-follower-content:has(> .tb-more){max-height: calc(100dvh - 16px); overflow-y:auto}`。
- **实测（695 档）**：弹层 `高 420px（max-height=420px）overflow-y=auto scrollH=217 clientH=217`，
  21 项 → **5 项**，底部完整落在视口内。

### 五、改 bug 时踩到的一个坑（留给后来者）

首版把 `out.evidence.moreFormats` 写成 `width: width`，但 `nestedPopoverProbe(frame, out)` **没有 width 形参**
（只有 `ctxMenuProbe(frame, out, width)` 有）。`ReferenceError` 让 promise 链静默 reject，
表现是「150s 内没拿到断言结果」+ 一张与改前字节完全相同的截图 —— 极易误判成"构建没生效"。
修法是函数内补 `var width = out.width;`。**教训：探针里引用未定义变量不会报错到控制台，先加 step trace 再猜。**
