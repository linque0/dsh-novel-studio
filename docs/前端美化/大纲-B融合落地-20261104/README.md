## 还原和接入

1440×900 下实测顶栏为 84px；三栏为左 `(28,108,220,762)`、主 `(264,108,814,762)`、右 `(1094,108,318,762)`，栏距 16px。品牌与 LATENT、标题、结构栏搜索框、首个结构行、详情标题与梗概、关联章节与关系行的字号、行高及纵向位置均与 B 基准对照测量。详情分区已恢复阅读呈现，点击标题、正文、状态原位编辑；设置齿轮、真实保存提示和六项导航已接入。

主窗口与独立窗口复用 `OutlineWorkspace`；宽屏左右并排、窄屏互斥抽屉。左右可拖宽、方向键调宽、双击/Home复位；默认 220/318px，尺寸和开关分别存入既有 appconfig。实际宽度不足时临时限制侧栏，不覆盖记忆值；收放与调宽不修改相机、缩放或节点坐标。右栏关闭后普通选择不强开，恢复时显示最新选中项。

容器复用原层级和展开数据：无保存展开偏好时仅展开根容器；已有 `expanded`（含空数组）保持原意。进入、返回、多层嵌套、归组、移出、撤销重做及关系投影沿用现有实现。普通纸卡、内部卡片与玻璃容器区分显示，全文在详情或文本视图编辑。

样式生成脚本直接读取获批 B HTML 的组件规则，并限定于 DSH 大纲根节点；交互适配集中在 `app/plugin/dsh/outline-layout.css`。旧桌面详情组件保留，新详情仅在插件大纲工作区使用。公共 API、数据库结构没有迁移。

## 明确的差异与限制

1. 自由画布根据真实容器关系排布；B 稿的全书平铺与进入容器后的画布内容不同。统计、章节、人物、关系标签由实际数据派生，不写死成示例；全页差异图包含这些内容差异，不作为像素完全一致的证明。普通选中纸卡另以同缩放、同尺寸做局部对照。
2. 为避免 B 原稿底部创建栏与缩放栏相交，创建栏向左移动 17.5px。宽屏画布底部保留78px安全区，较窄主区保留122px；跨层前接/后续单独占行，避免压住纸卡。长内容通过画布平移/缩放浏览，页面没有横向溢出。
3. C 的全书总览可缩小到48%以定位全书；另有95%阅读状态实图，可点100%或进入容器恢复阅读尺度。内部卡只展示摘要，完整正文保留在详情与文本视图。
4. 对照取证固定为原稿同一背景静帧；正式产品继续使用书架共享的动态背景。自由画布仍保留四向连线锚点，原稿只画了三个可见点。
5. 本轮验证在真实浏览器加载插件构建产物及隔离模拟宿主中完成，尚未在真实 DSH 客户端进行人工打开验收。
