## 设计取舍

使用紫灰颗粒背景、暗色玻璃、宋体页名和六项导航。左侧236px分类与检索，右侧工作区；外观页将常用偏好和正文预览并排。数据页把操作与内容摘要并排，备份恢复先展示内容规模，再明确确认替换。

范围依据现有插件设置：不加入模型、知识库、主题、皮肤或纸面切换。没有本机目录迁移能力时，不展示迁移、清理目录或重启操作。

手机页头去掉重复位置说明；分类按需展开。预览页带可直接操作的中文字体与字号控件，调整与结果保持在同一视野。日常保存状态集中在顶栏，底栏说明设备归属；旧反馈随新操作收起。

删掉了重复的页头气氛说明、预览操作解释和备份建议，腾出空间给设置项、正文和回收站入口。

## 可以体验

1. 中文字体6种、西文字体3种，字号13–24px；默认思源宋体、跟随中文、17px。字体从本地资源加载，正文实时呈现结果。
2. 默认隐藏顶栏开关、恢复默认与撤销；修改自动保存，刷新恢复。保存失败保留当前选择并提供重试。
3. 搜索设置、字体名与常用词；从结果定位到具体控件。空结果有清除入口。
4. 同源窗口同步偏好，同时保留各自正在查看的分类与阅读位置；未保存选择不会被外部更新覆盖。
5. TXT/Markdown导入创建新作品；按作品、章节导出真实文件。完整备份生成JSON文件，恢复前校验并展示规模，勾选确认后才替换原型数据，可撤销恢复。
6. 回收站分类筛选、恢复条目与确认彻底删除；写作概览从当前内容计算，帮助页提供实际支持的键盘操作。
7. 760/380px分类抽屉、焦点约束与归还、Esc关闭；预览中直接修改字体与字号。

动效用于按钮反馈、顶栏预览开关、定位高亮与弹窗短位移。减少动画设置下关闭过渡，背景停在静帧；未做录屏或帧率测量。

## 边界

这是独立设计原型，使用专用存储键 `latent-settings-design-v1`。演示内容为《长夜将明》及其人物设定；不会读取正式偏好或真实作品库。原型JSON备份有独立格式，不能用于替换正式插件的备份。

本轮实际实现TXT/Markdown导入导出；正式插件其他文档格式的解析引擎未复制。正式Vue设置组件、公共API、数据库和之前设计稿未改动；没有提交或发布。
