## 可以体验

1. 搜索姓名、别名、角色与标签，按角色或标签筛选；搜索无结果时可清除条件。
2. 阅读与编辑姓名、多角色、别名、标签、自定义字段及小传；上传头像、保存或取消。新建取消不留下空人物。
3. 草稿按人物 ID 保留，切换人物后可继续；保存失败保留输入，不显示保存成功。刷新恢复内容、草稿、筛选、滚动和布局。
4. 建立、修改和移除人物关系；关联设定在弹窗内阅读。删除人物前确认，之后可撤销恢复人物及两类关系。
5. 关系图选择联动、悬停高亮、节点拖动、空白平移、缩放、适应画布与聚焦；局部和全体网络各有独立排布。
6. 侧栏收起、拖动调宽、方向键调整、Home/双击复位。空间不足时临时限制侧栏，保留记忆尺寸。
7. 760/380px 使用单主区域与名录抽屉；支持 Esc、焦点约束、焦点归还与 Ctrl/Cmd+S。

三版共用《长夜将明》的8位人物、12条人物关系和6条设定关联；计数由内容计算。每版使用不同的本机存储键，互不覆盖。全部数据均为原型内容，不连接真实作品库。

## 设计与复核

A 的人物小传为阅读主角，关系和设定保持首屏可见；B 用人物字标和卡册形成群像索引；C 用关系组织空间，窄屏重新排布而非机械缩小桌面图。

删除了 B 页头重复的气氛说明，为卡册留出更多空间。名录增加人物级草稿标记，文字最小11px，小传正文14–15px。普通玻璃保留品牌材质；弹窗、输入与关系节点分层清晰。

动效包括按钮状态反馈、侧栏收放、关系邻接高亮、弹窗短位移和共用流动背景；减少动画设置下关闭过渡并固定背景。对比页固定同一背景静帧，独立页使用既有 flow 引擎及其 CPU 降级。

独立视觉复核：初稿发现头像按钮隐式提交、新建取消残留、C 重复表单及无效返回入口，均已修复并加入验证。第二轮复核后，C 手机画布改为紧凑树形；最终确认所有姓名可见。最终静态评分：A 8.5/10、B 8.0/10、C 8.0/10。评分只针对截图，未做录屏或帧率评估。
