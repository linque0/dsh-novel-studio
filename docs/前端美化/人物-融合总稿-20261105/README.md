## 融合方式

- **人物卷宗为主**：248px人物名录 / 连续档案 / 304px关系与设定。阅读态直接呈现身份、姓名、小传与侧写，编辑入口明确。
- **关系剧场辅助探索**：220px人物名录 / 关系画布 / 332px人物档案。图中选人同步档案，完整阅读入口直接回到同一人物的卷宗。
- **两种视图共用上下文**：人物、角色/标签筛选、搜索词与草稿共享；切换不提前保存、不串写。每个视图独立记住栏宽、收起与滚动位置；图谱按局部/全体、人物、设备尺度分别记住视野中心与缩放。刷新恢复上次视图。
- **手机重新编排**：目录使用抽屉，卷宗与图谱均为单主区域；点击图中人物进入档案，返回后保留视野。默认局部图使用紧凑树形，人物姓名与五条关系均可直接读清。

沿用紫灰颗粒背景、暗色玻璃、宋体姓名、姓名字标头像及六项导航。保留字段、小传、头像上传、关系增删改、关联设定阅读、删除撤销、保存失败保留输入、键盘调宽与焦点管理。
