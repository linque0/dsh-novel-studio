## 5. 与总稿的差异清单（逐项：现象 / 原因 / 影响）

1. **恢复备份的撤销**：总稿是内存回滚（`model.mjs:40-41`）；正式版恢复必须 `reload`，内存态熬不过重载，所以改为"恢复前把全量快照写进 `sessionStorage['novelstudio:settings:restoreSnapshot']`，重载后数据页给出「工作区已从备份恢复。」+ 撤销，撤销＝用该快照再恢复一次"。快照 >4MB 不写并提示不可撤销；>10 分钟或损坏直接丢弃并清键。
2. **预览正文用真实数据**：总稿是固定演示文本（长夜将明）；正式版取当前作品首章前 3 段（html 先 `stripTags`），无作品/空章才逐字回退总稿演示句与拉丁行。作者已确认（D3）。
3. **导入/导出文案按真实能力**：总稿写「TXT 或 Markdown」；正式版导入支持 TXT/Markdown/DOCX/PDF/EPUB/图片、导出支持 TXT/Markdown/Word，页内说明与检索目录 `desc/terms` 一律按真实能力写（两处必须一字不差）。导出弹窗因此多第三项 **Word**。作者已确认（D4）。
4. **导出弹窗章节复选框**：总稿 `.form-field input{width:100%;padding:9px 11px}` 会把 `.chapter-pick` 里的复选框压成一列竖排（稿面截图 `export-dialog.png` 本身即此状态）；正式版用内联样式复位为行内复选框。属"不复刻稿面缺陷"。
