## 打开

[三版对比页](style-explorer.html) 支持并排、单张和实际尺寸100%查看，也可在页内直接交互。对比页已内嵌脚本、字体与背景，可单文件离线查看。嵌入预览中的修改仅在该预览会话保留。

完整体验使用三份独立页面；通过本地预览地址打开时，内容和布局分别持久化到本机浏览器，三版互不影响。

- [A · 设定书房](a-study.html)：纸页编写、层级整理、关联资料按需展开。
- [B · 世界档案](b-archive.html)：设定集、条目列表、阅读详情三栏；推荐作为正式界面的优先候选。
- [C · 关系观测台](c-observatory.html)：局部关系图、条目详情和人物关联联动。

目录内运行 `python -m http.server 57890 --bind 127.0.0.1`，打开 `http://127.0.0.1:57890/style-explorer.html`。也可直接打开离线对比页。独立页面需要与 assets、studio.css、fonts.css、prototype.js 一起携带。

## 设计与空间

三版共用《长夜将明》：6个设定集、18个主条目、6个子条目与2个人物、13条关系；默认选择雾港灯塔。所有计数来自这份内容数据。原型采用书架与获批大纲的紫灰颗粒背景、玻璃外壳、宋体标题、六项胶囊导航。A 的纸页和 C 的人物节点提供各自的视觉重心。

1440×900首屏中，顶栏84px，工作区y108，左右28px，间距16px。A为236/1132px；B为220/300/832px；C为180/824/348px。正文限制行宽，玻璃只承担外壳，正文与纸卡不受背景干扰。

- A：连续编写的白色纸页；默认露出编辑按钮，直接点击标题/正文也能编辑。关联资料占用独立侧区，窄屏按单区域呈现。
- B：先看条目摘要，再阅读正文；关联关系进入首屏，对象名称优先于关系名称，子设定随后展开。返回原条目恢复正文滚动，筛选和列表位置保留。
- C：默认仅显示当前条目与一跳关联。可拖节点、拖空白平移、滚轮或按钮缩放，双击节点或聚焦按钮切换中心；关系方向区分出入向，悬停联动列表。

## 可以体验

1. 点击分类、搜索内容或标签、从结果跳转；标签点击后可清除。
2. 编辑标题与正文；输入时显示待保存，保存、取消及切换条目均有对应反馈。草稿绑定原条目，切换不会写入新条目。打开搜索等弹窗后编辑表单状态保持一致。
3. 新建条目、子条目和标签；删除前确认，删除后撤销恢复子树与关系。
4. 添加、移除与撤销关系，搜索关联对象，跳转到设定或人物。
5. A底部条目区：Enter紧随当前条目新建同级，Tab/Shift+Tab调整层级；拖手柄重排或归组，禁止放入自身及后代。
6. 侧栏收放、拖动调宽、方向键调整、双击或Home复位；刷新恢复独立尺寸。调宽不提前提交编辑。
7. 760/380px单主区域浏览；目录为按需抽屉，支持焦点约束和Esc关闭；B返回列表、C返回图谱时保留上下文。
8. 右上齿轮可撤销、重做与恢复本方案初始内容。

全局导航仅保留当前模块状态，其他模块按钮不跳出原型。示例数据只用于设计比较，不映射真实作品；无公共API、数据模型或数据库改动。

- 编辑、筛选、关系弹窗与长标题状态为 `*-edit.png`、`*-filter.png`、`*-relationship.png`、`*-long-title.png`。
- 机器结果见 `report.json` 与 `explorer-report.json`；最终复核记录见 `verification/`。

构建：`node tools/build.mjs`（使用仓库已有esbuild）；交互验收：`node tools/verify.mjs`；模型测试：`node --test tools/model.test.mjs`。`content.json`为唯一内容源，构建生成content.mjs与prototype.js。

背景采用同一静帧保证比较公平；状态切换、按钮反馈和面板呈现有轻量动效，尊重减少动画设置。正式动态背景与真实模块接入待选稿后实施。
