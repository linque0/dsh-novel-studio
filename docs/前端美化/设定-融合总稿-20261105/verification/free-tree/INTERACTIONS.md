# 自由节点树交互实测 · 2026-11-06

对象：同一设计总稿 index.html，经只监听 127.0.0.1 的 tools/preview.mjs 提供。真实浏览器操作；测试内容已在原型中清理。

| 操作 | 观察结果 |
| --- | --- |
| 点击雾港灯塔圆点 | 当前标题为雾港灯塔，只显示其后代；相对缩进归零 |
| 点击守灯规程圆点（380×844） | 当前标题、祖先路径随层级变化，无横向溢出 |
| 点击折叠箭头 | 隐藏后代，当前聚焦标题保持不变 |
| 点击文字双链 | 侧边显示目标内容，主区仍停在原节点 |
| 从侧边查看点击进入 | 进入目标节点并关闭侧边查看 |
| 后退、前进 | 依次恢复守灯人协会与雾港灯塔；恢复各自位置 |
| 新建根节点并修改名称 | 建立“潮雾笔记”，Enter 从标题进入第一个子节点 |
| 连续输入、Enter | 海雾观测、潮汐记录成为两个同级节点 |
| Tab / Shift+Tab | 第二节点相对深度由 0→1→0，文本保留 |
| 普通节点 Shift+Tab 到顶层 | 海雾观测出现在根节点列表；可撤销 |
| 节点中间 Enter | 海雾观测拆成“海雾”“观测”，后续节点保留 |
| 一次 Ctrl+Z | 一次恢复为原来的海雾观测，无后文丢失 |
| H 菜单选择二级标题 | 行获得 heading-2，树深度仍为 0 |
| 输入 [[雾港并回车 | 出现匹配目标列表；插入 lighthouse ID 链接；未额外创建同级节点 |
| 刷新 | 当前根、节点文本与 ID 链接保持 |
| 进入链接目标并查看反链 | lighthouse 的引用计数从 2 增至 3，新增来源包含潮雾笔记 |
| 阅读、层级导图、关系网络 | 均能打开同一节点；层级导图有 9 个节点，关系网络有 7 个节点；未见控制台错误 |
| 手机打开设定目录 | 出现目录抽屉；聚焦和返回保持主内容可读 |
