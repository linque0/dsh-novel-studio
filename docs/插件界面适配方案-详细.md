# 插件版界面适配方案（详细）——基于 DSH 当前界面的实测调研

> 两件事同时成立：① 界面必须是**小说工坊的完整界面**（大纲/人物/设定/画布/统计全在）；② 外观与交互必须**长在 DSH 里**，而不是自带一套美术。
> 本方案只改前端可视与交互，不改功能；并把**插件版**与**桌面版**从构建、产物、皮肤、发布上彻底分开。

---

## 第一部分 · DSH 当前界面表现（实测，2026-11）

### 1.1 度量（本机实测）

| 项 | 实测值 | 说明 |
| --- | --- | --- |
| 屏幕 | 2048×1152，系统缩放 125% | DSH 窗口物理 1978×1036 → 逻辑约 1582×829 |
| 左侧栏 | 物理约 310px → **逻辑约 248px** | 品牌行 + 新会话 + 导航（插件/任务看板/智能体/更多）+ 工作区树 + 底部动作区 |
| 会话列 | 逻辑约 1088px，正文栏最大约 720px 居中 | 字号 14px、行高约 1.75 |
| 右侧栏 | 本次未展开；只有 28×28 的两个图标按钮挂在右上角 | 展开后是「页面的一列」，宽度可拖，**<768px 打开自动全屏** |
| 输入区 | 底部卡片，圆角 16，内含「+ / 完全权限 / 模型选择 / 发送」，右下角显示 tok/s、缓存命中、上下文占用 | 控件高度 28–34 |

### 1.2 视觉语言（决定插件皮肤的样子）

1. **半透明玻璃层**：本机装了壁纸/角色类第三方插件，左栏与输入区都是**半透明**的，壁纸透过来；界面靠 0.5px 描边与极轻阴影分层，而不是靠不透明底色。
   → **插件界面绝不能铺一块不透明大底**，否则壁纸主题下会像贴了一张纸。正确做法：只读宿主令牌现值（可能是半透明），必要时用 `backdrop-filter` + 0.5px 描边。
2. **中性灰阶 + 一处强调色**：文字三级（label-primary / secondary / caption），强调色来自主题插件（本机偏蓝紫），不由插件自造。
3. **紧凑密度**：控件高 28/34，列表行 34（紧凑变体 24），字号 11/12/13/14/16/18/20/24，圆角 4/8/12/16/20。
4. **动效克制**：120–180ms ease-out，只有淡入/位移，无装饰动画。
5. **焦点环**：宿主统一 `:focus-visible`（浅色 #4176E6 / 深色 #7AAAFF，2px），插件不自定义 outline。

### 1.3 令牌与组件几何（读宿主样式表核实，插件直接复用）

| 类别 | 值 |
| --- | --- |
| 底色 | 浅 `#fff` / 深 `#151517`；抬升面 `#fff` / `#232324` `#2c2c2e` `#353638` |
| 描边 | `border-l1..l4` = 4% / 10% / 12% / 16% 透明度的黑白 |
| 圆角 | 4 / 8 / 12 / 16 / 20 |
| 字号阶 | 11 / 12 / 13 / 14 / 16 / 18 / 20 / 24，正文跟随用户设置 `--dsh-content-font-size` |
| 按钮 | 高 28（sm）/ 34（md），圆角 8 / 12 |
| 列表行 | min-height 34，padding 6×8，圆角 12；紧凑 24 / 2×6 / 圆角 8 / 11px |
| 页签条 | 容器 padding 4、圆角 16；tab 高 34、圆角 12 |
| 输入 | 高 28、padding 3×8、0.5px 描边、圆角 8 |
| 浮层 | `--dsw-specific-menu` 材质 + `--dsw-menu-backdrop-filter` + `--dsw-elevation-prominent` + 圆角 16 |
| 滚动条 | `--dsh-scrollbar-width/thumb/thumb-hover` |

### 1.4 插件可用的落点

- 唯一落点是**右侧栏 tab**（`ctx.sidebarRightTabs` + `ctx.slots.register('sidebar.right.pane.tab')`），入口是右侧栏「开始」页的卡片；
  左栏底部那枚「工坊」启动器与卡片重复，已下线（2026-11）。
- 面板是「页面的一列」：取会话地面色与正文字号，不是浮起卡片；超窄自动全屏，全屏时覆盖视口。
- 同源 iframe：可注入样式、可读写 iframe 的 `documentElement` —— 令牌桥因此可行。
- 右侧栏「开始」页的卡片栏：宿主 `TabRegistry.refresh` 只把 `definition.guide ?? []` 摊平成卡片，
  所以入口要出现在这一栏，tab 定义必须带 `guide: [{ id, order, title(), description(), icon }]`；
  卡片点击走 `openTab(kind)`，正文座位（`sidebar.right.pane.tab`）必须按同一个 `id` 注册。
  这两条由 `npm run contract` 的客户端预检（`scripts/client-contract.mjs`）守着。

## 第二部分 · 插件版与桌面版的项目分隔

### 2.1 现状问题

现在 `dsh-novel-studio/assets/app` 是桌面版 `novel-studio/dist` 的原样拷贝，两边的皮肤、AI 面板、窗口行为完全一致——这就是「两个项目被混成一个」的根源。

### 2.2 分隔方式（推荐：同一份源码，两套构建目标，插件专属层单独成目录）

| 维度 | 桌面版 | 插件版（DSH） |
| --- | --- | --- |
| 源码 | `novel-studio/src`（唯一源） | 同一份源码 + 插件专属层 `novel-studio/plugin/dsh/**` |
| 构建 | `npm run build` → `dist/` | `npm run build:plugin` → `dist-plugin/`（额外：注入 dsh.css、关闭恍然梦 AI 面板、皮肤注册表过滤为只剩 dsh、剔除未用皮肤 CSS/字体） |
| 皮肤 | 5 套任选（原版/引力/琉光/赤月/主题书） | **只有 dsh 一套**，不可切换 |
| AI | 内置恍然梦面板 | AI 面板整体不渲染，位置换成「DSH 会话」状态位 |
| 窗口 | Electron 主窗口 + 拆窗 | 只有 iframe 面板；无拆窗、无全局快捷键 |
| 数据 | 作品库（`%LOCALAPPDATA%/novel-studio/library`） | 同一作品库（有意共享，作者一份稿） |
| 发布 | Electron 安装包 | `dsh-plugins/dsh-novel-studio` + profile bundle |
| 版本 | `novel-studio/package.json` | `dsh-novel-studio/package.json`（独立版本号，记录所基于的桌面版 commit） |
| 目录 | `src/{components,stores,skins,styles}` | 只在 `plugin/dsh/` 下放：dsh 皮肤、插件入口覆盖、构建配置；**插件专属改动不得回写桌面版目录** |

规则三条：
1. 共享层只做「参数化」（例如 `skin registry` 增加 `audience: 'plugin'` 字段、AI 面板受 `window.__NS_AGENT__` 控制），不写死插件分支。
2. 插件专属的视觉与交互一律落在 `plugin/dsh/`（CSS 与少量包装组件），删掉这个目录即可回到桌面版外观。
3. 插件仓库 `dsh-novel-studio` 只消费 `dist-plugin` 产物，构建日志里打印桌面版 commit，便于追溯。

## 第三部分 · 插件界面适配规格

### 3.1 令牌桥（插件侧 `src/client/iframe-shim.js`）

- 读父窗口 `getComputedStyle(document.body)` 的 `--dsw-*` 与 `--dsh-content-font-size`，写入 iframe `documentElement` 的自定义属性（前缀 `--ns-*`），并给 `body` 打 `data-ns-host="dsh"`、`data-skin="dsh"`。
- `MutationObserver` 监听父窗口 `body` 的 `data-ds-dark-theme`、`style` 变化（第三方主题插件改令牌时也会触发），变化即同步，不重载 iframe。
- 若某个令牌取不到（宿主版本差异），用内置浅/深两套回退值，不回退到小说工坊的五套皮肤。

### 3.2 变量映射（应用变量 ← 宿主令牌）

| 应用变量 | 取宿主 | 备注 |
| --- | --- | --- |
| `--bg` | `--dsw-alias-bg-base` | 页面地面；壁纸主题下本身可能是半透明 |
| `--bg-panel` `--bg-editor` | `--dsw-alias-bg-layer-1` | 面板与纸面；需要极轻微 `backdrop-filter` |
| `--bg-hover` | `--dsw-alias-interactive-bg-hover` | 行/卡 hover |
| `--text` `--text-dim` `--text-faint` | `label-primary` `label-secondary` `label-caption` | 三级文字 |
| `--border` `--border-strong` | `border-l2` `border-l3` | 统一 0.5px |
| `--accent` `--accent-soft` `--accent-deep` | `state-business-primary` + 12%/20% 透明 | 选中、进度、链接 |
| `--danger` `--success` `--warning` | `state-error-primary` `state-success-primary` `state-warn-primary` | 语义 |
| `--radius-sm/md/lg` | `--dsw-radius-sm|md|lg` | 8 / 12 / 16 |
| `--fs-xs/sm/md/lg/title` | 11 / 13 / 14 / 16 / 18（跟随 `--dsh-content-font-size` 增量） | 字号阶 |
| `--shadow*` | `--dsw-elevation-soft|panel|prominent` | 只有浮层用阴影 |
| `--ease` `--dur*` | `cubic-bezier(.2,.8,.2,1)`、120/180/240ms | 动效 |

### 3.3 去装饰清单（`plugin/dsh/skins/dsh.css`，预计 500–800 行）

- 去掉：纸纹/木纹/亚麻纹理背景、艺术字标题（文楷/宋体竖题）、异形卡片与斜切边、彩色高光渐变、装饰性描边与角标、皮肤专属插画（`GlazeArtwork` 等）。
- 统一：0.5px 描边、圆角 8/12/16、控件高 28/34、辅助字号 11/12、行高 1.6–1.9、图标 16/20 描边。
- 保留：所有功能控件与信息层级；封面图改为小尺寸圆角缩略（不用整屏画框）。

### 3.4 各模块适配要点（只改外观与容器，不改交互逻辑）

| 模块 | 改什么 | 关键规则 |
| --- | --- | --- |
| 书架 | 木纹/展示台 → 卡片栅格；书籍封面改缩略图 + 标题 + 元信息 | <560 单列、≥560 两列、≥768 三列，卡片圆角 12 + 0.5px 描边，hover 抬到 `--dsw-alias-bg-layer-2` |
| 顶栏 | 高度压到 36px，去掉品牌画框与皮肤选择器 | 作品名 + 当前页签 + `⋯`（其余动作进菜单） |
| 工作台 | 左章节树 230→236px 或窄栏细轨；编辑区中性纸面；工具栏只留高频 6 项 | 编辑区最大行宽 36em、行高 1.9、字号跟随宿主 |
| 大纲 | 去纸纹、节点卡片中性化、连线降饱和 | 画布交互（拖拽/缩放/连线）**一行不改** |
| 人物 | 卡片列表 + 字段表（两列标签/值） | 字段表用 0.5px 分隔线，不用卡片套卡片 |
| 设定 | 树（左）+ 详情（右）保持，去纹理与竖排标题 | 树行 34px、选中 `interactive-bg-active` |
| 图谱 | 去发光与纹理，节点用 `bg-layer-2` + 0.5px 描边 | 力导向/布局代码不动 |
| 灵感/片段 | 卡片列表 | 标签用 pill（圆角 999 + `corner-shape: round`） |
| 统计/回收站/设置 | 表单密度对齐 DSH（行高 34、输入 28、分组标题 11px） | 危险动作用 `state-error-primary` 文字，不用整块红底 |
| 导入/导出 | 对话框圆角 16 + `elevation-prominent` | 遮罩用 `bg-mask-2`，不模糊 |
| AI（恍然梦） | 不渲染；原位换成一行「AI 由 DSH 会话承担 · 回到左侧对话」 | 不给按钮，避免误导 |

### 3.5 两档宽度

- **窄栏 <560（默认落点）**：单栏。顶栏 36px 一行；章节树折成 22px 竖排细轨，点开为 280px 浮层抽屉；右资料面板改底部抽屉，默认收起；编辑器页边距 12px；工具栏 6 个动作 + `⋯`。
- **宽 ≥768（宿主全屏）**：三栏。左 236 / 中自适应（行宽 ≤36em）/ 右 280；顶栏与三栏同宽对齐。
- 两档之间（560–768）：两栏（左 236 + 中），右面板仍为抽屉。
- 全屏由用户触发（宿主 fullscreen 呈现）；插件不强行改呈现模式。

### 3.6 壁纸/第三方主题下的可读性

- 面板内部不铺不透明大底；需要衬托的浮层才用 `--dsw-specific-menu` + `backdrop-filter`。
- 文本只用 `label-*` 三级；不用 50% 灰自造，避免壁纸透出后不可读。
- 图片类（封面）加 0.5px 内描边，避免在花背景上糊边。

## 第五部分 · 风险与不变项

**风险**
1. 皮肤 CSS 特异性打架：沿用 `body[data-skin="dsh"]` 前缀提高特异性；`!important` 只允许用于去装饰三类。
2. 组件内联样式里的少量硬编码色（如 `#9a382e`）：M1 列出清单逐个换成变量（改样式字符串，不改逻辑）。
3. iframe 双滚动条：抽屉与浮层要归位 `overflow`。
4. 53.9MB 产物：`build:plugin` 时裁掉未用皮肤与字体（预计可降到 20MB 内），首屏只加载必需资源。
5. 宿主版本差异：令牌取不到时用回退值，不崩。

**不变项（硬边界）**
- 不改 `stores/`、`db/`、`services/`、`electron/` 的任何逻辑；diff 里不应出现这些目录。
- 不改大纲画布、关系图、图谱的交互代码（只改 CSS）。
- 桌面版默认体验不变：构建 `dist` 时不含 `plugin/dsh/` 的任何样式与开关。
