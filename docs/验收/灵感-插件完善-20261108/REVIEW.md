# 独立复核处理记录

方式：一名无对话历史的评审者，先按存量界面润色标准独立看图，再做只读代码复核。不打分，不让评审者修改代码。

| 复核发现 | 修正与证据 |
|---|---|
| 手机目录比总稿宽，目录方角 | 统一255px宽、16px圆角、距视口12px；五档目录测量与手机对照图通过 |
| 详情有双边框、双滚动条 | 外层统一承载滚动，内部整理组件去除重复容器；`detail-380.png` 已检查 |
| 外部修改冲突后，旧草稿无法继续保存 | 展示当前保存版本，明确核对后才更新草稿基准；包括不含指纹的旧草稿，专项检查通过 |
| 带草稿入回收站仍显示编辑表单 | 回收站优先只读和恢复，草稿挂起保留；恢复后继续编辑，专项检查通过 |

保留：开放侧栏、薄荷色选中计数、真实标签独立列、仅标签滚动、底部回收站。正式宿主84px顶栏与原型66px顶栏的差异不靠侧栏偏移修补。

主执行者另查：只读手机详情聚焦关闭按钮，避免打开即唤起键盘；明确进入编辑才聚焦输入。几何检查等待有限动效结束，允许0.01px浮点误差，字号与内边距仍按计算样式精确比对。

最终60项正式页面检查在1440、1280、864、760、380px连续三轮通过。实际输入法与实体手机硬件未在本轮使用；组合输入通过事件回归，软键盘通过视口高度变化模拟。
