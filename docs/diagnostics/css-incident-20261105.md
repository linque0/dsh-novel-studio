## 教训（已写入项目记忆）
1. 大文件禁止「read(limit) → 整体写回」，只能用定点替换或追加。
2. 同一批文件禁止并发派单；样式文件必须串行或按文件所有权切分。
3. 大规模改动前必须有版本控制回退点；本项目 `app/` 此前未跟踪，是这次无法还原的主因。
