# 小说工坊产品片 V3.2：逐场景动画与连续创作旅程方案

日期：2026-11-09。依据用户四张问题截图及“每个场景都要有相应动画效果，不能干放展示”的最新要求修订，替代上一版冲突条款。本轮交付优化计划，尚未改动成片、采集素材、插件业务逻辑或作者作品库。

## 1. 四处问题与修改决定

| 画面 | 问题判断 | 新版决定 |
|---|---|---|
| 图一：书架与大标题 | 作品偏小，包装占空间；品牌和书架重复，停留缺少动作 | 合并为约6秒：完整书架建立、一次作品切换、进入《雾港纪年》。取消诗句大标题和02/20计数，不再重复静态书架 |
| 图二：一句话的大纲文本页 | 大片空白没有说明能力，放大也没有信息收益 | 删除独立文本视图镜头，改为约23秒真实画布操作：七类模块的用途、连接建立、属性与节点移动后的连接效果 |
| 图三：人物关系图 | 核心节点与底部关系被裁，静止局部没有新信息 | 完整人物页先建立，关系图先适配全部节点与边，再观察一组完整关系；增加实际选择/定位反馈 |
| 图四：版本历史弹窗 | 遮暗正文、内容重复，割裂创作流程 | 删除该弹窗及独立镜头，以正文批注的创建、分类、定位替换；同步删除历史快照准备要求 |

用户最新规则优先：**界面介绍尽量完整，具体功能可以特写。** 取消上一版“完整界面至少80%”“仅两次特写”“所有结果统一停三秒”的限制。保留写作分析中的原生“修改记录”，它与本次删除的版本历史弹窗是不同功能。

新增硬性要求：**14个内容单元及其中独立展示的子视图，都必须设计与功能相符的动画动作。** 不能只让背景流动、鼠标移动或字幕出现，然后静态摆放截图。每段交代起势、主动作、结果落定和接续；阅读时短暂落稳是动作弧的一部分，不等于取消动画。具体安排见第8节。

## 2. 保留约束与制作路线

保留《雾港纪年》、真实DSH插件前端、Tom Cardy《Lo-Fi》原唱、无旁白、无歌词字幕、无AI操作。时长90–120秒，当前按约115秒分配，最终按完整乐句与实际操作耗时锁帧，不改变音高或整体速度。

色板：漫画红#EF3426、明黄#FFD84A、深墨蓝#14203B、奶油白#FFF3D0。红黄流动和网点用于视频背景，保留原生封面、控件和文字颜色；阅读段降低背景亮度及运动幅度。Video Shotcraft负责镜头语言，HyperFrames负责制作。

| 路线 | 取舍 |
|---|---|
| 连续工作台＋按操作需要改变观察距离 | 采用。全景交代位置，特写讲清功能，原生导航和关联承担转场 |
| 全程完整录屏或固定全景 | 用作素材骨架；成片中关键文字过小，节奏层次不足 |
| 每项功能独立包装成动画卡片 | 放弃，会重现PPT式割裂感 |

叙事线：书架→灵感“陆离的沉默”→大纲“守塔人的证词”→设定“白鹭号”→人物“陆离”→c5《灯塔下的证词》编辑、阅读和批注→写作分析→排版与数据保管→回到作品。没有原生直达关系时使用实际导航，不制作虚假自动联动。

## 3. 构图、停留与字幕

### 全景和特写分工

- 每个模块首次出现，先展示完整应用视口，交代导航、工作区和当前原生面板；不要求长页面的全部滚动内容同屏。
- 1920×1080成片中，默认完整界面1664×936，位置(128,24)，保持16:9并使用contain。旧1728×720容器必须撤掉：源界面按1728宽适配需要972高，旧容器会裁去252px。
- 界面建立通常约0.8–1.4秒，接着发生可见操作；这是草剪参考，不是固定模板。
- 功能特写按目标包围盒计算倍率，不限制次数。完整显示所需逻辑单元：卡片和菜单、原文和批注、连线两端和标签；不截标题、按钮、段落行尾。
- 同一功能内可以连续跟随相邻目标，不必每点一次按钮都拉回全景。换模块或丢失空间定位时再回完整界面。
- 长内容通过真实滚动展示；画布通过原生平移/缩放展示。不能用摄影机切掉页面边界后仍称为完整页。人物图总览必须容纳所有演示节点和边。
- 不临时隐藏关键控件。需要读字时用真实字体偏好或完整逻辑单元特写，避免整页被缩成小贴图。

### 按信息量分配停留

以下是动作完成后的稳定阅读窗口，不是整段镜头长度；最终以正常速度观感调整。

| 信息 | 草剪参考 | 阅读目标 |
|---|---|---|
| 选中、保存、搜索命中 | 约0.5–1秒 | 看清状态变化即可，光标可开始前往下一目标 |
| 一张模块卡、单条关系、排版变化 | 约1–1.8秒 | 看懂一处重点，不要求读全页面 |
| 批注内容、连线语义、导入/恢复差异 | 约1.8–2.8秒 | 同屏或连续给出对象与依据，看懂因果再继续 |
| 品牌收尾 | 约1–1.3秒 | 产品名落定、音乐收句，不拉长尾帧凑时长 |

不统一三秒保底，也不按固定秒数强切。画面连续约两秒没有新动作、信息或必要阅读时，标为节奏复核点；确有阅读任务可以保留。不能用持续漂移代替节奏。

字幕区域在应用外：x=128、y=980、宽1664、高76，底部稳定墨蓝带；字号64px、行高76px，实际有效字高至少56px。每次一行短功能结论，建议14–18字，最多24全角字，不叠眉题。片头片尾另作构图，署名字高至少32px。字幕跨同一操作接缝保留，不每次点击重新飞入。

## 5. 大纲：七类模块与连接的23秒主镜头

已核对当前源码：事件、便签、引用卡、文本框、容器、章节锚点、卷均为原生模块。关系支持关联、因果、伏笔、冲突，单向/双向/无向、标签，实际拖线以及移动节点后的路径更新。以下为待采集设计，不声称前端动态效果已经实测通过。

### 演示画布准备

旧演示大纲只有事件与单条文本，不足以说明功能，需要在隔离作品补齐内容：

- 事件：“收到无邮票来信”→“旧船坞发现铜钥匙”→“守塔人的证词”，各有一至两句摘要与可辨状态。
- 便签：“铜钥匙与白鹭号日志对应”；文本框：“本幕目标：让证词推翻沉船时间”。分别说明临时线索和持续可见的长文字说明。
- 引用卡：实际绑定设定“白鹭号”，结尾可原生点击进入该条目。
- 容器：“灯塔疑云”，包含两个真实子事件，能就地展开/收起，或进入再返回。
- 章节锚点：实际绑定c5《灯塔下的证词》；卷卡绑定演示库实际存在的卷，显示真实章节数和字数。若无卷，先通过现有前端在隔离库创建，不伪造计数。
- 预置少量因果主线、伏笔虚线与关联支线，为新建关系留出清晰落点。模块有内容、层级有用途、标签不交叠，原生线网不靠后期装饰线代替。

### 内部分镜与运镜

| 段内时间 | 真实动作 | 镜头与功能结果 |
|---|---|---|
| 0–1.2 | 完整大纲工作台及画布总览 | 工具、侧栏、画布、当前详情区完整；直接看见模块与线网 |
| 1.2–3.7 | 选事件“守塔人的证词”，改短摘要或状态 | 观察完整事件卡及所需详情范围：事件承载情节和进度；不进空白文本页 |
| 3.7–6.2 | 便签原位补短句，沿相邻文本框观察说明 | 两个完整单元共用一次观察移动，不逐字读长文；分别讲清提醒与长说明用途 |
| 6.2–8.5 | 引用卡选择已有“白鹭号”目标并绑定 | 保留真实目标选择和卡片更新；此时不跳走，结尾再点击同一引用 |
| 8.5–12 | 容器展开，看见子事件，再收起 | 说明故事分组与层级；就地展开/收起或进入/面包屑返回二选一，以隔离实测为准，不两套都演 |
| 12–14.5 | 章节锚点选c5，既有卷卡显示对应卷与真实汇总 | 展示正文映射与卷级概览，不把它们当装饰方块；此处不跳出画布 |
| 14.5–20.8 | 从事件锚点实际拖线；设关系类型、短标签；小幅移动节点 | 源、目标、整段连线、属性菜单完整。主操作一条因果线，既有伏笔虚线作对照，其他类型在真实菜单可见，不逐项巡演 |
| 20.8–23 | 回完整网络，点击“白鹭号”引用进入设定 | 新线仍保留；真实引用跳转承担转场 |

提前把模块按观察路线排好：事件→便签/文本框→引用→容器→章节/卷→连接，再一次归位。已有模块可以预置，不必把所有新建表单拍一遍，但每种模块必须有用途和可见内容。

拖线前镜头落稳，由线条和光标运动；不追着线头甩镜。必要时小幅平移，最终源、目标与标签同框。连线类型/标签编辑和节点拖动时，不叠加强推近。验收实际关系保存、标签与方向可辨、节点移动后端点仍绑定且路线更新；容器操作不吞掉关系。跨层投影若要拍，必须单独实测，不把未验证能力写成既定画面。

全段保持c5《灯塔下的证词》，承接前段编辑/阅读，从编辑态真实选区创建，不假定阅读模式能创建。

删除旧方案中等待五分钟生成历史快照等全部采集前置要求。本片不再录制版本历史弹窗。

## 7. 人物、分析与数据段修正

人物页短建立后，关系图先原生适配全部演示节点，核心节点不得落在下边缘外。实际选中陆离，观察一组完整关系，再原生导航正文；若前端无选择高亮，就用实际点击定位/打开资料，不后期伪造。取消局部静态关系图长停。

写作分析四视图分别只承担一个重点：当前字数、真实创作日期、章节分布、c5修改记录。完整工作区短建立后可以观察原生图表/列表，不在两秒内要求读完整仪表盘，不做四宫格。数据来自构造的真实演示记录，不编造增长。

数据演示保持同一目录位置以便比较：导出展示真实文件内容；导入展示新增条目和正文；恢复展示新增补遗消失、基线目录回来；回收站展示同一条目回原列表并可打开。基线必须在导入前保存。剪掉无信息等待时，仍保留选择、确认和结果因果。

## 8. Video Shotcraft转场与动效口径

| 语言 | 采用方式 | 约束 |
|---|---|---|
| cursor-flyover | 光标先行、相机跟随、真实反馈，用于大纲相邻模块与批注观察 | 不照搬均分四站，不每站归位；菜单、输入、拖线和阅读阶段相机落稳 |
| deck-deal-flyin | 灵感手札→拼板，仅一次真实卡片归位 | 卡片落原生槽位后接标签/搜索，不另开展示板 |
| 原生关联/导航＋位置匹配剪辑 | 引用→设定、设定→人物、人物→正文 | 保持同作品、窗口边界与操作位置；没有直达功能就走实际导航 |
| 原位状态匹配 | 连线、批注、排版、导入恢复和回收站 | 不靠叠化制造假中间状态，前后目标可追踪 |
| 封面轻量空间运动 | 片头最多一次小幅推进或抬升，品牌和书架合并 | 整页边界不越界；撤掉上版候选穿窗mask-wipe，不增加额外过场 |

### 8.2 动画节奏、真实界面与完整性

- **每段有一个主运动，子功能有明确反馈动作**：例如大纲主运动为连续画布观察，连接子段靠实际拉线/跟随；正文批注靠选区、面板对应和定位。不能用同一段慢推近覆盖整段功能作为完成标准。
- **不以背景代替前景动画**：只有红黄背景流动、光标游走、字幕淡入的段落不算通过。既有静态素材必须配有效的镜头观察或素材层动画，能采集原生动态时优先实际操作。
- **分开原生变化与后期包装**：原生输入、展开、连接、重排、定位和数据前后状态必须真实录制；后期负责镜头、整窗轻量空间变化、文件展示层和字幕，不改写结果。统计不做假增长，图连线不虚构逐条生成。
- **动画重叠而非排队**：入场末段接操作，操作结果接观察落定，离场起势接下一入口；不形成“先播完整入场动画→静放截图→再播完整退场动画”的新PPT结构。
- **控制同时运动的层数**：同一时刻优先一个主动作；正文、菜单和连线属性需要读时相机落稳，背景轻动可以保留。完整界面转正/位移使用约12–18帧起落，功能观察约12–24帧，复杂卡片动作约24–36帧，最后按音乐锚点与实测调整。
- **不重复主效果**：发牌只在灵感当一次主角；人物转正只作一次短入势；大纲的拖线是功能演示。其他场景以各自功能变化形成区别，不全片统一飞入、推近和甩镜。
- **完整页与特写分别验收**：整页动画的每帧均保留完整视口边界；功能特写保留目标逻辑单元。不得为了全景动画抬升、倾斜或放大而再次切断页面。

## 9. 素材与工程执行顺序

1. 复用现有完整高分辨率原始素材重新适配，不从已裁切MP4反向扩图。重点补录七类模块、真实连线、完整人物图、同章批注、跨模块导航及必要数据结果。
2. 隔离采集1920×1080逻辑视口，整页2倍、关键元素至少4倍，动态功能用清晰视频。只替换`.ls-backdrop`和`.st-backdrop`背景参数，排除封面；GPU红黄替换失效即停止采集。
3. 隔离库可以预置内容，但成片声称的创建、连接、分类、定位、导入、恢复必须实际执行。正式业务逻辑、作者作品库、API均不改动。
4. V2保留对照；后续V3独立工程使用六个连续HyperFrames场景：A书架00–06、B灵感06–17、C大纲/设定/人物17–56、D正文/批注56–79、E分析/数据79–112、F收尾112–115。内容单元14个，不再固定20页或15镜。
5. 唯一`film-manifest.json`记录素材、镜号、原生目标包围盒、动作/反馈/阅读区间、接缝重叠、音乐锚点和章节帧，剪辑、网页、HLS章节表同源。每个内容单元及独立子视图补记`motion.intent`、`motion.enter`、`motion.main`、`motion.settle`、`motion.exit`及各自帧区间，区分原生录制与后期动画，禁止出现没有有效主动作的空配置。
6. 先完成整支低码率动态草剪至收尾，正常速度连续观看与试听，先消除等待、裁切和因果断裂，再做正式渲染。不再停在孤立短样片或风格帧。

相机、应用窗口、字幕独立；整页适配、局部适配、场景转换分别计算。同场景背景不重置时间，跨素材匹配相位，避免色块跳变。

## 10. 音乐与验收

先人工试听Lo-Fi起止完整乐句，再冻结约115秒编排；不直接沿用旧未通过的局部节拍网格。保持原唱连续感与音高/速度，拟音只点缀翻动、点击和落定，不盖原唱，真峰值≤−1dBTP。本文件不声称已试听或连续看片。

- 节奏：书架不重复；无变化长停有阅读依据，动作推动下段；不套统一三秒停留模板。
- 逐场景动画：14个内容单元及各自独立展示的子视图均有可辨主动作和结果落定；按第8.1节逐项核对。只有静态截图、背景流动、鼠标游走或字幕动画均不算通过；全片正常速度观看还须验证动势接续和效果不过度重复。
- 取景：模块首次有完整界面；功能特写目标完整；人物图无核心节点被截，大纲线两端、标签和箭头可见；无图二式空白主镜头。
- 大纲：七类模块都有实际用途；至少一条真实新关系完成类型、标签设置，移动节点后线跟随，最终完整网络保留结果。
- 批注：创建、用途颜色、侧栏定位真实对应，无失效锚点；成片不出现版本历史弹窗。
- 数据：导出文件、导入新增正文、基线恢复差异、回收站返回原列表都有可见证据。
- 连续性：正常速度检查进入作品、大纲引用→设定→人物→正文、正文→批注、导入→恢复→回收站；不能只看抽帧。审查无法连续观看/试听时记录未验证，不签发观感通过。
- 文字：字幕安全区、有效字高和480px缩略播放验证；主结论与目标可辨，不要求所有原生小字逐字可读；放大时确保清晰行尾和完整控件。
- 输出：1080p、30fps、H.264/yuv420p、AAC、BT.709，无黑帧、露底、尾漂、明显削波或音画漂移；锁定音乐锚点关键切点误差≤三帧。
