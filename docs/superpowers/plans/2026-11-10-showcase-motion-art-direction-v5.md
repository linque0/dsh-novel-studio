# V5：恢复人物视差镜头，为各功能设计主动画

2026-11-10。基于现有V4工程增量设计；保持真实界面、《雾港纪年》隔离库、红黄风格、原唱配乐、旧版片头片尾。用户附图是人物镜头的视觉基准。本轮交付设计与素材回收、闪烁诊断，不将尚未渲染的设计描述为已完成成片。

## 核心决定

恢复的是旧人物镜头的完整动作弧：**分层横移 → 沈砚居中 → 卡片抬升 → 清晰落定**。不只放回一张截图，也不恢复旧版大诗句、镜号或宽扁裁切。

全片统一空间、阴影、缓动和色板，各功能的主动作则由其用途决定。界面间的短衔接与界面内的主动画分开编排。不能仅给页面加平移、缩放或背景运动，就算完成界面介绍。

- 主界面：1920×1080真实画面完整适配至1664×936；页面介绍必须能看到导航、主体与相关侧栏。
- 功能特写：完整呈现当前操作的逻辑范围；允许临时将真实卡片、纸面、节点或侧栏前置。
- 主阅读层无模糊、不变形、不重绘文字；仅远景与掠过的非阅读前景使用固定景深。
- 宋体字幕继续留在界面外；不把旧标题和镜号带回。黄色细描边在主角落定时出现一次，不脉冲、不绕圈群发。
- 相同强主动画只用一次。人物用多平面视差；灵感保留发牌；导入用行嵌入；其余用各自的结构和操作因果。
- 总长暂保持3586帧／119.53秒及既有音乐选段。下表为现有章节预算，最终动作关键帧须对真实音乐瞬态核验。不能为卡拍压缩真实结果。

## Video Shotcraft具体依据

已校验本地Gallery索引、卡片与准确TSX：

1. `depth-layer-moves · multiplane` → `MultiplaneReal.tsx`：人物恢复的核心；保留层速梯度、单驱动、反算终点与抬升时序。
2. `deck-deal-flyin · deck-deal-flyin`：沿用已完成的灵感主镜头，原有真实卡片发牌不重做。
3. `cursor-flyover · cursor-flyover`：大纲与操作段沿真实操作提前转移视线；不把光标涟漪当场景主动画。
4. `document-typewriter-reveal` → `DocumentTypewriterReveal.tsx`：正文仅借鉴纸面空间相机与平滑后撤。**不照搬假打字、历史条目、标语或呼吸发光**，真实输入仍由录屏承担。
5. `row-embed · row-embed` → `RowEmbed.tsx`：导入结果单行离面后严丝合缝嵌回，按真实目录坐标和纸面底色匹配；不用模板中的底边闪光，避免本轮闪烁观感。

后两项属于明确的局部语法适配，不宣称完整复刻卡片变体。其他界面为依据真实结构的自定义编排，不杜撰Gallery名称。相应TSX已归档在full/references/。本地Gallery视频缺失，不能声称已与动态参考样片完成比对。

## 闪烁：已查到的问题与制作阻碍项

对V4全3586帧做相邻／短间隔A-B-A候选扫描，再回看实际帧。已复核 **f2264／75.4667秒**：批注用途编辑区只出现一帧。相同状态存在于 `assets/v3/annotations.mp4` 的f180，以及剪后素材f171，说明问题在源操作记录中已存在，不能归因于最后MP4编码。

处理：在隔离库重录“展开用途 → 可读等待 → 选择考据 → 分类结果稳定”，保留实际选区和定位验证；不使用全片插帧、模糊、叠化或复制一帧掩盖问题。该处未经重新采集及复核不得进入V5正式成片。

扩大到1／2／3／5帧间隔后，检测得到26个候选帧，包含同一事件的重复命中以及正常灯光、藏切等误报，**不等于26处真实闪烁**。已查看全部六张候选拼图，补充以下制作阻碍／复核项：

| 位置 | 已观察事实 | 分类与处理 |
|---|---|---|
| f2235–2236，约74.50–74.53秒 | 批注弹窗局部突然放大占满工作区，随后返回全页 | 已追溯原始录屏：`raw/annotations/f000135.jpg` 为1168×657，出现在相对5.0336秒；恰好16:9，被旧脚本只检查宽高比的过滤放行并放大。采集污染，必须重采或从有来源证据的原始完整视口帧重建 |
| f3015，约100.50秒 | 导入段回收站窗口瞬间放大再缩回，且当前画面语义与导入标题不符 | 取景闪跳和功能语义都须核对；定向重录实际导入→新增章节→正文结果，不沿用这段错误窗口 |
| f2900，约96.67秒 | 数据面板短暂放大再返回 | 已观察到异常尺度交替，待追溯源帧；纳入定向重采／修复范围 |
| f2638–2639，约87.93–87.97秒 | 分析画面右侧短时出现明显矩形底色边界 | 图层／截图纹理不连续候选；对照原素材与合成各自帧后定位，不直接认定编码原因 |
| f780–782，约26.00–26.07秒 | 大纲相机短时发生较大位移 | 待分清原生画布移动与包装相机叠加；巡航改用单一相机驱动，减小加速度突变，不用快移掩盖内容 |

已证实的采集根因是：`capture-v3.mjs` 在screencast进行期间执行带clip／scale的 `Page.captureScreenshot`，而 `repair-v3-timestamps.py` 把任何近似16:9的帧都当成完整视口。**后续录屏与高清元素截图分两次独立采集；录屏期间禁止局部截图及视口／DPR切换。** 每帧保存完整CDP元数据及视口状态；校验已知尺寸、页面缩放与操作阶段，不能仅凭16:9归一化。可疑帧不得静默放大混入正式素材。

当前扫描是候选检测，不能据只检出某些候选而宣称全片无闪烁。其它待验证来源分别处理：

- **采集状态**：短暂弹窗、悬浮工具条、焦点丢失、截图导致的临时尺寸变化；逐帧核对原素材，必要时重录操作。
- **媒体就绪**：字体、贴图和视频帧未就绪时切入，或seek后呈现旧帧；在渲染准备阶段完成解码与GPU预热，按固定帧时钟取帧。
- **合成接缝**：旧过渡端点与新主动画错配、层重复入场或提前卸载；重取全部受影响端点及短过渡素材，不拿V4旧PNG接V5新动作。
- **背景／网点**：固定种子、坐标与相位；外层背景不能因章节切换重新启动。检查细网点在720p／480p的采样，不用每帧随机噪声和透明度脉冲制造质感。
- **图层与滤镜**：避免共面层深度争用、动画中切换CSS zoom与transform、全屏动态blur或渲染后端中途改变。主阅读纹理不叠两份，不在硬切点同时重启相机。

## 制作顺序与验收

1. 保留V4成片、清单与源码基线；从已归档旧版恢复人物运动函数，适配当前完整画框。
2. 先重录确认的批注瞬态问题，并对其他候选分类；只补缺失操作与元素，不改插件逻辑或作者作品库。
3. 在原有六个主合成中逐个加入主动画，参数／阶段写回唯一film-manifest；旧构建与最终修饰入口保持一致。
4. 先出覆盖全片的动态草剪，连续检查“起势—主动作—落定—接续”，再正式渲染；不以单张styleframe或孤立样片代替整片检查。
5. 主场景画面锁定后，重新提取全部受影响桥端点；同对象交接必须同内容、同坐标、同背景相位。音乐锚点及字幕时长重新核对。
6. 在源素材、HyperFrames母版、最终MP4、三档HLS四层检查稳定性；扫描所有帧，候选前后至少12帧原尺寸回看；普通接缝检查前后不少于6帧，复杂镜头按整段检查。
7. 全片正常速度连续观看与试听必须另列记录，不能用contact sheet或数值检测代替；人物／正文还需480px宽缩略播放检查。审查输入缺失则标记未验证。
8. 黑帧、突闪、未就绪旧帧、单帧界面跳变、背景重启及主阅读层糊字均为交付阻碍项。修正后重跑相关范围，再由干净上下文审查完整成片及抽帧。

后续交付仍为带配乐／无配乐保留音效两版、三档HLS、海报截图、章节及可复现工程。本设计阶段不覆盖已交付V4，也不发布网站。
