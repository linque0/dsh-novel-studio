# 小说工坊 · DSH 插件版：Video Shotcraft 第二版创作提案

日期：2026-11-08。阶段：用户已授权依据本方案制作三镜样片，14.8 秒样片已使用 Video Shotcraft + HyperFrames 完成并通过独立复核；[样片工程与复现说明](../../../showcase/production/shotcraft-v2/sample/README.md)。完整功能片的分镜仍为候选，本轮未扩展为整片制作。

用户已选：**90–120 秒精剪版**。建议目标约 **115 秒**，最终服从《Lo-Fi》的完整乐句，可在范围内调整。此前 257.8 秒整曲版保留为历史版本，停止沿用其镜头时间表。

## 1. 这次要达到的效果

让第一次接触产品的小说作者，在约两分钟内理解：从灵感、大纲、世界与人物，到正文、修订和作品管理，整个创作过程都能在小说工坊里完成。

主线：**一个念头，长成一部小说。**

演示作品仍为《雾港纪年》。以“没有邮戳的来信”“停在 4:17 的怀表”“白鹭号沉船”串起真实页面，让功能之间有内容上的因果关系。

用户要求保留：Tom Cardy《Lo-Fi》原唱、无旁白、无歌词字幕、无 AI 操作；当前正式插件界面；隔离演示数据；真实功能结果；同一总片的网页章节跳转。网页、HLS、海报等原交付目标继续保留，等新版镜头与章节锁定后更新。

## 3. 创作路线与建议

| 路线 | 适合之处 | 取舍 |
| --- | --- | --- |
| 直接替换 Ink Press 模板 | 有完整成熟镜头结构，容易快速建立统一风格 | 小说工坊的紫色玻璃、中文排版和多种画布，与模板纸墨材质不完全契合，强套会弱化产品辨识度 |
| 自主定制 | 根据真实界面设计整片，可连续制作 | 用户只能较晚看到整体运动质感，当前已有一次质量返工，继续全片先行成本较高 |
| **共同创作、定制视觉（建议）** | 先用风格帧和短样片证明质感，再进入整片 | 多一个前期审片节点，能在制作量很小时修正方向 |

本轮交付的是第三条路线的完整候选方案。下一阶段建议先审三张风格帧与 12–15 秒运动样片，再冻结分镜。当前不把推荐方向视为用户已确认。

## 4. 视觉方向：隐现 · 故事生长

### 产品视觉依据

从当前源码提取，不另套无关品牌皮肤：

- `app/plugin/dsh/language.css`：Noto Serif SC / Source Han Serif SC / Songti SC 标题；系统无衬线工具文字；胶囊顶栏；暗色三级玻璃。
- `app/plugin/dsh/flow-shell.css`：流动背板、点阵与颗粒、玻璃主面与侧栏、约 20px 圆角。
- `app/src/styles/snippets-fusion.css`：暗紫底 `#211a2b`，表面 `#2e253b`，主文 `#f4edf4`，薄荷绿 `#bde5ce`，薰衣草 `#c7b7e4`，低透明度边线 `#e9d2f32c`。

制作前再读取运行页面的 computed styles，冻结完整 tokens、字体文件与背景种子；上述颜色是当前源码依据，不是允许改动插件外观的清单。

### 构图与文字

- 1920×1080、30fps。真实页面占主体，字幕放在空出的边缘区域。
- 少量宋体主标题，约 64–80px；功能短句约 30–36px；重点 UI 文本在成片中的有效字高以约 24px 为目标。需要读正文时靠近局部，避免缩小整页硬读。
- 主要内容距左右边约 96px、上下约 72px；字幕距底部约 100px，避开播放器控制区与关键按钮。
- 文案一次一句，通常 8–14 个汉字。只有片头、创作段落过渡、片尾允许大字主导。
- 一处焦点、一条主运动。远景可以退焦，正在展示的文字层保持锐利。

### 运动语法

1. **聚焦**：封面成为单一主角，光线、推进、悬浮、归位形成完整动作弧。
2. **汇聚**：灵感卡片从实体卡堆进入真实页面格位；加速发生在卡片间隔，不让相机按每个鼓点抖动。
3. **连接**：事件连线自然延伸到设定场景；全片只用一次完整线条接力。
4. **深入**：人物与设定分成前、中、后三层，平滑滑轨有明确终点；阅读时回到接近正视的机位。
5. **落笔**：关系图的文字锚点与正文中的同名文字对位切换，主角从空间结构变成段落。
6. **回收**：片尾召回出现过的页面局部，收拢在作品旁，最终只留下作品与产品名。

过冲、运动模糊、灯光均服务动作。大幅度整画面冲击默认不用；如样片证明需要，全片最多两处，间隔至少 16 拍。功能阅读段不做呼吸缩放、扫光或镜头尾漂。

## 5. 音乐方案与时间预算

已对本地 257.8 秒音源进行 librosa 初测：全局约 **84.9997 BPM**，约 0.7059 秒一拍。4/4 的四拍分组仅作为排镜预算假设，待试听乐句确认；40 个四拍组约 112.94 秒。

**这不是已验收的拍点表**：初测最大跟踪残差约 56ms，粗分频瞬态存在重复与误检，尚未通过技能要求的网格覆盖、漂移及鼓点分类验收。故下表使用秒数预算，不标注虚假的精确帧号。

音乐剪辑先交一个 110–118 秒左右的试听候选：完整起句 → 展开段 → 较舒展的正文段 → 有明确落点的收尾。尽量使用连续段落；需要缩短时只在乐句边界拼接，保留完整歌词句，不切在元音或呼吸中央。交叉淡化避开主鼓瞬态，片尾给音乐约 1.5–2 秒自然退场。

试听候选通过后：检查 85/170 BPM 的节拍层级，重新拟合局部网格与 kick/snare/hi-hat 瞬态，校验拼接两侧节奏与相位；用 `beatF(n)` 锁定镜头锚点，渲后从成片音轨回测，视觉锚点偏差不超过三帧。

音效只建议使用轻微触键、纸卡掠过、连线笔擦、落定轻叩这几类，具体素材留到样片阶段选。原唱始终清楚，不逐卡叠加撞击声，不叠旁白或歌词字幕。最终测量真峰值，目标不超过 -1dBTP。

## 8. 素材与实现计划

1. **冻结产品状态与内容**：记录当前正式插件版本 / 源码状态；只使用隔离《雾港纪年》，统一人物、设定、灵感与章节。按“输入 → 操作 → 结果”整理镜头证据。保留原库和现有未提交改动。
2. **三张风格帧**：A 封面与品牌聚焦；B 新版灵感看板与卡堆；C 正文与批注。分别检查中文排版、玻璃材质、明暗、有效字高、字幕安全区。风格帧作为方案输出，不用生成模型伪造产品界面。
3. **12–15 秒运动样片**：从 01、04、12 各取一段，使用真实音乐与字幕，覆盖慢镜、快镜、静读三种情况。先证明稳定相机、卡片重量与文字清晰度，再扩展全片。
4. **最终采集与分层**：全页 2x 纹理（1920×1080 CSS 视口对应 3840×2160 像素）；主角元素 4x；每段同时保存真实操作视频、状态截图、透明局部与 `layout.json`。动态背板单独留底，分层处补齐空槽，避免双影或切片露馅。
5. **Remotion 分镜实现**：独立 `showcase/` 内制作目录，镜头组件与交互采集分开，公共 tokens、统一相机坐标、确定性随机种子。FFmpeg 用于解码、音频剪接、封装与 HLS；核心镜头使用分层场景实现。
6. **统一章节**：唯一内容清单保存镜号、模块、素材、音乐锚点、起止帧、字幕与网页章节。先编辑预算，锁片后导出正式时间表。网页按钮使用正式章节的稳定入点，避开转场中段。
7. **逐镜审查与整片审查**：每镜检查起、动、落、停；整片核对能量变化、功能完整性、音画关系、文字与安全区。终检由未参与制作的独立审查者出带时间码 / 帧号的意见。
8. **最终交付**：带音乐 MP4 与同时间线无 BGM 版（保留选定 SFX），1080p30 H.264/AAC；海报、真实截图、章节表、可编辑工程与复现说明。通过后更新同一总片 HLS 的 1080p / 720p / 480p 与展示网页，再进行未登录和移动端验证。

三个质量门槛：静帧像商品海报；运动样片在正常速度下能读懂；整片每项关键操作有真实可读结果。不能只以成功编码、没有报错作为视觉验收。

## 11. 样片与成片验收

- 正常速度下能说明“谁在动、为什么动、动到哪里”；静止关键帧可独立作为产品海报。
- 真正使用当前正式 UI；录制来源、素材版本、小说条目对应一致；产品外观未经包装层重绘。
- 单镜只有一个主要运动，光源一致，阴影随抬升变化，快速运动有克制模糊，终点无抖动。
- 每个关键功能结果约三秒可读；字幕不压正文、按钮、曲线和版本时间。文字清晰度按最终 1080p 检查。
- 无黑帧、素材越界、切片重复、空槽暴露、透明边缘、强透视小字、音画漂移或削波。
- 导出文件确有内容，导入确有章节，备份重载确有恢复，回收站确有返回原列表；每项保留证据。
- 最终章节来自同一时间线清单；网页 1440 / 768 / 390px、章节跳转、失败重试、海报、原生 / hls.js 播放与全屏继续按原计划验收。
