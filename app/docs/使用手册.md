# 小说工坊 · 使用手册

> 本地优先的长篇小说桌面创作空间（**幻流**工作台），输入即自动保存，把灵感、大纲、人物、世界观与正文收在同一处。当前软件版本号可在「⚙ 设置 → 帮助与关于」查看。

---

## 一、快速上手

### 工作台全景

核心创作链路：`灵 · 灵感` → `纲 · 大纲` → `人 · 人物` → `设 · 设定` → `文 · 正文` → `析 · 写作分析`

- **3D 书封书架**：按连载、完结、构思或搁置筛选书目，卡片直显字数与上次停靠章节。
- **顶部胶囊导航**：居中胶囊一键在书架、正文、大纲、设定、人物与灵感间顺滑切换，可在设置中默认隐藏。
- **弹性侧栏视野**：拖拽边栏边缘自由调宽或折叠为窄边标签，双击分隔手柄恢复默认宽幅。
- **独立拆窗对照**：将正文、大纲、人物、设定或分析拆成独立窗口并排查看，内置实体锁防止多窗冲突。

### 三步开写

1. **新建或切换书目**：在书架新建作品，或在「⚙ 设置 → 备份与数据」导入现有书稿（支持 `TXT` / `MD` / `DOCX` / `PDF` / `EPUB`，导入前支持分章预览）。
2. **梳理大纲与设定**：用大纲理清主线，在人物卷宗与世界观设定中沉淀角色与规则。
3. **专注正文创作**：进入三栏写稿台沉浸落笔，随时通过双链、彩色批注与写作分析复盘。

## 二、核心创作模块

### 文 · 正文写作

> 三栏沉浸写稿，结构清晰且输入即存。

- **分卷分章目录**：按卷与章管理全书目录，支持关键词搜章、★ 书签收藏与拖拽调序。
- **沉浸富文本稿面**：支持标题、加粗、对齐、字色与高亮排版，顶部实时追踪章节目标字数。
- **随章五项资料栏**：右栏自动同步本章批注、本章大纲、自动识别出场人物、本章插图与字数信息。
- **自动存盘与快照**：停笔即自动保存，每 5 分钟留存历史快照（最多 30 份），随时预览回滚。
- **进阶技巧**：折叠左右栏让稿纸居中展开，点「阅读」切入限宽只读模式（`Esc` 逐级退出）；选中正文右键可添加用途色批注或 `[[关系链接]]`，同句叠加互不遮挡。

### 纲 · 故事大纲

> 画布与文本双视图联动，理顺长篇脉络。

- **画布与文本互切**：右上角无损切换自由画布与缩进幕布，两套视图共享同一份剧情数据。
- **多样情节模块**：自由摆放事件（4 种形状、4 种状态）、便签、引用、文本框、锚点、分卷与容器，双击空白速建。
- **语义连线自动绕障**：拖线区分关联、因果、伏笔与冲突，挪动卡片自动避障且两端接口不漂移。
- **全书结构侧栏**：左侧树形目录同步显示全部层级，点击即可自动跨层居中定位节点。
- **进阶玩法**：容器支持「就地展开」迷你卡或「进入容器」下钻子画布；拖线落到连线上可建中途连接点，拖弯连线可手动塑形（双击还原）；`Ctrl + K` 跨层级速搜，📌 固定模块在整理布局时不动。

### 人 · 人物档案

> 从卷宗细节到关系剧场，一眼看清人物网。

- **多维检索名录**：按姓名、别名或标签实时搜索，支持角色定位与标签组合筛选。
- **立体角色卷宗**：上传头像、勾选多角色定位、撰写多篇独立小传，并自由增删自定义字段。
- **故事坐标速览**：右栏集中呈现当前角色的一度关系与关联设定，点击直达关系剧场。
- **关系剧场拖线**：拖线连接两位角色新建关系，拖向已有连线即可原地修改或删除，支持圆形/网格一键排布。
- **进阶玩法**：关系剧场支持切换「一度关系 / 全部人物」并标记孤岛人物；右键节点可发送为大纲引用卡，小传右键支持插入 `[[关系链接]]`。

### 设 · 世界观设定

> 一棵统一节点树，三种视图掌控世界观。

| 视图模式 | 定位 | 适用场景与核心能力 |
|---|---|---|
| **节点大纲** | 录入与整理 | 无限嵌套幕布树，键盘快速缩进、自由拖拽层级，支持行内富文本、贴图、`MD / TXT` 按标题导入与撤销重做 |
| **三栏阅读** | 查阅与复盘 | 左目录、中同级卡片（带标签筛选）、右详读卡并列呈现，适合边写边查关联与逐级下钻子条目 |
| **视觉导图** | 全景与推演 | 内置「层级导图」展开树状分支与「关系星系」3D 轨道鸟瞰，直观呈现全书设定与跨模块连接 |

- **条目权重分级**：支持为条目或标签分配 `核心 / 关键 / 标准 / 点缀 / 末节` 五档权重，条目自动继承最高权重标签。
- **进阶玩法**：右键条目选择「设置关系…」建立双向关联，双击条目进入专属详情页。

### 灵 · 灵感拼板

> 按标签分栏收纳灵光，一键落入正式稿件。

- **按标签分栏收纳**：灵感按标签自动分栏展示，支持参考图片、网址收藏与 6 种柔和配色。
- **图钉拖拽理顺**：拖住卡片顶部图钉即可调整组内顺序，或跨栏拖进其他标签组重新归类。
- **自由调节看板**：左下角切换最新、最早或手动排序，滑杆连续缩放卡片大小，误删可在回收站找回。
- **一键转入正文设定**：右侧整理抽屉支持宽幅编辑，点击「转为章节」或「转为设定」落入正式结构并保留原卡片。

### 析 · 写作分析

> 离线统计码字节奏与全书规模，随时复盘。

- **随手看写作速览**：点击顶栏统计图标 📊 立看当前正文字数、章节数、今日净增与近 7 日柱状图。
- **创作历程与对照**：查看区间累计净增曲线与活跃日历，支持拖选日期范围或同屏对照两部作品走势。
- **章节与改稿轨迹**：分析分卷字数分布与完成度，沿章节 × 日期热力矩阵回看每章改稿净差。
- **全模块资产盘点**：分项统计大纲、设定、人物与灵感规模，点击图表直接联动右侧详情。

## 三、进阶与拓展功能

### 关系星系与 3D 导图交互

| 操作 / 按键 | 效果 | 说明 |
|---|---|---|
| `左键拖拽空白` / `方向键` | 旋转 3D 星系视角 | 松手带惯性平滑滑行，键盘方向键可微调角度 |
| `中键拖拽` / `Shift + 左键` | 平移画布视野 | 自由移动星系中心在画面中的位置 |
| `滚轮` / `双指捏合` | 缩放视野远近 | 拉近自动渐显低权重细节条目 |
| `单击星域 / 条目` | 下钻星域或查摘要 | 点设定集飞入其内部星域；点条目在右栏看摘要 |
| `拖动边缘卡尺` | 调节星体与条目大小 | 悬停边缘出现缩放手势，拖拉即生效并记忆 |
| `拖拽星域` / `轨道编辑` | 调整轨道与并轨 | 调整轨道半径与角度，靠近另一轨道松手自动并轨 |
| `右键星体` | 调节公转 / 自转与大小 | 可单独设定公转速度、自转速度百分比或恢复默认 |
| `右键中心星体` / `Shift + F10` | 定制中心发光样式 | 切换配色来源、光影动效、亮度与动效速度 |
| `Esc` | 逐级退回 / 取消 | 关闭浮层、取消选中或返回上一级星域 |

- **图层与布局**：底部图例胶囊（`条目织网` / `集内关系` / `跨集关系` / `关联对象`）支持点击显隐与悬停独显；底部「布局」可调轨道间距并一键「暂停运转 / 恢复运转」。
- **层级树状导图**：支持单向/双向分支、肘形/贝塞尔连线、按层折叠、双击行内编辑与拖拽重挂接。

### 跨模块双向关联与下钻

- **设定 ↔ 设定 / 设定 ↔ 人物**：右键设定条目选「设置关系…」或点击行尾关系卡，自定义正反向名称与说明后两端自动同步。
- **连线视觉区分**：`条目织网`（虚线，呈现设定集内结构脉络）、`集内关系`与`跨集关系`（实线分色，呈现手动建立的语义关联）、`关联对象`（卫星节点，双击直跳人物 / 大纲 / 正文 / 灵感）。
- **双击下钻详情页**：双击设定条目进入专属阅读详情页，集中查看正文、关联关系列表与编号子条目树。
- **全书 `[[关系链接]]`**：正文、大纲、设定与人物小传均可键入 `[[` 或右键插链，目标改名不断链；悬停预览窗按住标题栏拖动即可**钉住常驻对比**，双击标题恢复跟随。

### 效率与生态拓展

- **五级条目权重体系**：`核心`、`关键`、`标准`、`点缀`、`末节` 五档分级，条目可自动继承最高权重标签。
- **多格式导入与分级导出**：导入支持 `TXT` / `MD` / `DOCX` / `PDF` / `EPUB` 及设定 `MD / TXT` 层级导入；正文导出支持 `TXT` / `MD` / `Word (.docx)`，按阈值（默认 `30` 章，可调 `2–500`）逐章写入或超阈值合并 / `.zip` 打包。
- **独立拆窗与实体锁**：各核心模块可拆出独立窗口并排参考，主进程实体锁自动保护正被他窗编辑的条目。
- **幻流外观与离线字库**：支持深/浅色面板、默认隐藏顶栏、界面切换动画开关、WebGL 流动背景（跟随封面或双色自定义，`0–2×` 流速）以及 6 款中文 + 3 款西文随包离线字体（`13–24px`）。
- **常用快捷键**：
  - 全局与书架：`← / →` 切书、`Enter` 开书、`Ctrl + Shift + F` 全局搜索、`Ctrl + S` 立即保存、`Esc` 逐级关闭
  - 大纲与幕布：`Ctrl + K` 画布搜节点、`方向键` / `Shift + 方向键` 移模块、`Enter` / `Shift + Enter` 同级或换行、`Tab` / `Shift + Tab` 升降级、`Alt + ↑ / ↓` 上下移节点

## 四、数据安全与系统

### 本地优先保障

- **纯本地存储**：所有稿件、大纲、人物、设定与统计记录存于本机硬盘，不联网、不主动上传。
- **编辑即存零丢稿**：输入停顿 1 秒自动落盘、30 秒定时兜底，切章、失焦与关窗前强制存盘。
- **防并发冲突保护**：同一数据目录仅建议单实例运行，拆窗时由实体锁防止多窗双写覆盖。
- **实验性功能**：创作助手「恍然梦」、模型设置与知识库模型默认隐藏，可在「⚙ 设置 → 实验性功能」按需开启。

### 备份、迁移与版本

- **全库 JSON 备份**：在「⚙ 设置 → 备份与数据」一键导出完整快照，恢复前先核对规模再替换，建议每周定期备份。
- **存储位置一键迁移**：可查看当前作品库目录并整库迁至其他磁盘文件夹。
- **分类回收站与更新**：误删内容均可从回收站还原；在「⚙ 设置 → 帮助与关于」查看当前版本并检查官方更新（SHA-512 校验）。
