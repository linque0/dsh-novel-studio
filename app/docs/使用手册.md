# 小说工坊 · 使用手册

> 适用版本 v1.1.3 · 本地优先的小说创作软件：正文 / 大纲 / 人物 / 设定 / 灵感一站式管理，输入即存，永不丢稿。

---

## 1. 启动与数据

| 启动方式 | 命令 | 用途 | 数据目录 |
|---|---|---|---|
| 正式版 | `npm start` | 日常写作 | `%APPDATA%\小说工坊`（真实书目） |
| 开发调试版 | `npm run dev` | 改代码（热更新） | `%APPDATA%\小说工坊-dev`（验证书） |
| 安装版 | 安装程序 novel-studio-setup-x.x.x.exe | 分发使用 | 同正式版 |

- 全部数据保存在本机（IndexedDB），不联网、不上传；
- **同一数据目录同一时间只能开一个实例**，否则报 `DatabaseClosedError`；
- 多开隔离：加参数 `--profile=名字`（数据存到 `小说工坊-名字`）；
- 全部退出：`npm run stop`（同时清理开发服务，校验 5173 端口释放）。

## 2. 界面总览

- **顶栏（书架页）**：品牌区（「坊」标 + 小说工坊 Novel Studio）｜ 搜索框（书名/作者/类型）｜ ⚙ 设置 ｜ ＋ 新建作品
- **顶栏（作品内）**：← 书架 ｜ 书名 · 保存状态点 ｜ 🔍 搜索 ｜ ⧉ 拆窗 ｜ ⚙ 设置 ｜ 沉浸 ｜ 阅读（仅正文页）。设置中的「默认隐藏顶栏」只收起这一条应用级顶栏；赤月戏的模块工具条（标题 / 视图切换 / 整理 / 独立窗口）不随顶栏收起。赤月戏使用 76px 顶栏 + 86px 模块条 + 40px 底栏，五个模块各有独立布景。
- **⚙ 设置面板**：主题 / 中英文字体 / 正文字号 / 导入导出备份恢复 / 回收站 / 书签 / 统计 / 帮助的统一入口（详见第 11 节）
- **顶栏导航**：四皮肤书架与工作区共用 `AppTopbar` 七模块导航（正文 / 大纲 / 人物 / 设定 / 灵感 / 关系 / 更多）；原版不再使用书内左侧模块导航，赤月戏保留其模块工具条差异。
- **内容区**：条目栏（拖右缘调宽，双击手柄恢复默认）+ 主工作区

## 3. 书架与备份

- **书架陈列**：**原版工坊**使用色带书封——每本作品一张平涂单色封面，衬线书名 + 题材副标 + 作者名圆印（2 字竖排 / 3–4 字两行 / 1 字单行；未填作者则不盖印），新建/编辑作品时可选封面款式：虚构 · 克莱因蓝 / 非虚构 · 象牙白 / 文集 · 松绿 / 诗辑 · 藤紫 / 别藏 · 绛红 / 特殊 · 墨黑，每款配色冷暖对位，封面书名跟随当前正文字体（见第 11 节）；**引力书舱 / 琉光画境 / 赤月戏**使用各自的生成式书封（赤月戏为月轮、山影、题签与朱印）；
- **卡片信息行**：`x.x 万字 · n 章`；封面悬停出现 ⋯ 菜单（打开 / 编辑信息 / 删除）；
- **本地搜索**：顶栏搜索框按书名 / 作者 / 类型实时过滤，无匹配时有提示（与空架状态区分）；
- **新建作品**：书架页创建（可带首卷）；
- **导入**：支持 **txt / md / docx / pdf / epub** 自动按章拆分为新作品；图片需先打开一个作品；
- **备份**：⚙ 设置 → 数据 → 备份全部数据（JSON，含全部书目）→ 换机 / 重装时「恢复备份」一键还原；建议每周备份到网盘或移动盘。

## 4. 文 · 正文

- **章节树**：新建 / 重命名 / 删除（进回收站可恢复）；章节前 ★ = 已加书签；
- **富文本工具栏**：撤销/重做 ｜ 标题一/二/三 ｜ 加粗、斜体、下划线、删除线 ｜ 字体颜色、突出显示、底色 ｜ 有序/无序列表 ｜ 引用 ｜ 左/中/右对齐、两端对齐 ｜ 超链接 ｜ 清除格式 ｜ ☆ 书签收藏；
- **右键菜单**：选中文字右键——剪切/复制/粘贴 + **添加批注** + **添加关系链接**；
- **正文批注**：选中正文 → 右键「添加批注…」→ 填写批注内容并选用途色 → 确定；被批注的文字出现**实线下划线**（颜色即用途：待改红 / 疑问蓝 / 伏笔紫 / 灵感绿 / 考据橙 / 待定灰，也可用取色器自定义任意颜色），右侧「本章批注」栏逐条对应；点击条目即定位到正文位置并闪烁提示；侧栏可**编辑内容 / 改用途色 / 删除**，删除只摘掉批注、正文文字保留；光标落在批注内右键可「编辑批注 / 移除批注」。与关系链接互不冲突：关系链接是**点状线**贴字（主题色），批注是**实线**偏下（批注色）并带同色淡底，同一段文字可同时承载关系链接与批注；正文文字被整段删除后，批注自动转「已失效」，侧栏可一键「清理失效」；
- **自动保存**：输入即存，顶栏实时显示保存状态。

## 5. 纲 · 大纲（文本幕布 / 自由画布，右上角切换）

### 5.1 文本视图（幕布式大纲）
节点树：缩进层级、拖拽排序、行内编辑、导入 md/txt（标题层级自动转节点层级）、关系链接。

### 5.2 画布视图（自由模块画布）
- **放模块**：画布工具条是唯一入口，可直接添加事件（4 种形状可切换）、便签、引用、文本框、容器；「锚点」「卷」下拉可选择新建空白锚点或绑定已有章节/分卷。空白处右键新建与双击新建事件仍保留；连接点只能通过连线右键创建；
- **连接点（线连线）**：把连线接到另一条连线上的接线柱——**右键连线 → 编辑浮层 →「在此处创建连接点」**，连接点直接钉在右键位置对应的连线路径上；**创建后 1.6 秒内高亮显形**（加深圆点 + 光环）方便确认位置，随后自动淡出回微观透明态（不遮挡连线，悬停显形）；连接点是**双向接线柱**——既可以被模块锚点的拖线接入（作终点），也可以**直接按住它拖出连线**（作起点）；**按住连接点拖到另一条连线上，会在落点自动创建新连接点并接上（线连到线）**；一条连线可建多个连接点、各自引出多条连线；两方向的连线都以连接点中心为端点、沿宿主连线走向零桩直出，无缝衔接；**右键连接点 → 删除**（接到它上面的、从它引出的连线一并删除）；
- **模块操作（右键菜单）**：**右键模块**弹出操作栏——形状▸ / 编辑内容 / 透明度滑杆（文本框）/ 自定义类型▸ / 固定·取消固定 / 删除（红标）/ 容器分支调色板。**点选模块不再弹任何遮挡栏**；关闭菜单 = 点空白 / Esc / 执行删除或编辑；双击模块 = 打开设置抽屉，行内编辑改走右键「编辑内容」；
- **容器**：拖入即归组，▾ 折叠/展开，分支自动配色；**八向缩放柄恢复**，宽度 260–720、折叠最低 178、展开最低 220；缩到比内容矮时，迷你卡在容器内容区内部滚动，连线/端口跟随滚动；**容器内迷你卡可直接拖动**——容器内拖动按落点重排、**拖出容器即回到当前层（落点即新位置）**、拖到其它容器卡/迷你容器上换组；
- **连线**：拖模块四向锚点到目标模块/连接点即建立（拖到连线本体上自动建连接点接线）；**左键按住连线拖动 = 塑形**——拉弯、拉直自由调整（拖回贴近直线自动拉直；双击连线恢复自动路由）；**右键连线 = 编辑浮层**（标签、线型、颜色、箭头、线宽 + 在此处创建连接点），建边完成时也会自动弹出；选中连线后 Delete 键或工具条「删除」即删；连线从锁定端口出入，按**全局最短路径**自动绕开途经模块（现布局绕不开时以虚线「路径受阻」呈现，挪动模块后自动恢复）；连线编辑浮层固定屏幕尺寸，不随画布缩放变大变小，且**自动避线弹出**——按连线走向挑不遮挡连线本体的一侧（水平线弹上/下方，竖直线弹左右侧），并完整保持在画布可视区内；
- **⚙ 设置**：**画布透明度（20–100%）** 只影响底色/点阵，模块与连线保持不透明；连线粗细（0.8–5px）、**箭头大小（0.5–3.0×）**——全局默认值，单条连线可在编辑浮层单独覆盖；卡片密度、连线样式（曲线/折线）、16px 网格吸附；
- **视图**：总览、**展开全部 / 收起全部（递归当前作用域所有层级）**、整理（📌 固定项豁免）、缩放 ±、适应；撤销 ↶ / 重做 ↷。
- **分层画布**：根层只显示直接子节点，子容器显示为章节卡；点「进入容器」进入该容器的次级画布，面包屑返回上级并恢复各层相机。容器也可「就地展开」为两列迷你卡（窄容器单列），迷你卡可直接改文字、打开抽屉、拖端口连线、**拖动重排或拖出容器归组**；需要自由摆放时进入次级画布。
- **关系投影**：收起的子节点会投影到最近的可见容器卡（淡线 + 空心落点），当前层之外的端点收进上方「前接」/下方「后续」接续卡；同一对端点的同类关系合并为「类型 · N」，可在关系组浮层批量改类型/箭头/标签，点「详情」查看每条真实关系。
- **状态与多选**：事件状态为 已完成 / 正在写 / 待修改 / 待展开，新事件默认待展开，容器进度只统计已完成；工具条「多选」可勾选当前层节点（含迷你卡），≥2 个时一次撤销内封装为新容器；搜索（Ctrl+K）会自动进入目标父层并定位。
- **材质**：纸面材质默认启用，工具条不再提供素材库/纹理开关；所有内容卡缩放时纸面图按 100%×100% 铺满，事件形状随宽高缩放。素材只用于界面，不提供原图下载。

### 5.3 大纲侧栏
只保留「故事结构」树（点击定位画布）、搜索、类型筛选、自定义类型管理（⚙）；进入容器时自动展开当前容器及其祖先并标出「本层」，不再单独显示「本层模块」。侧栏右上角「‹」收起后，画布左缘保留「故事结构」竖标签，点击恢复；搜索与折叠状态在收起期间保留。

## 6. 人 · 人物

- **列表/详情**：小传 + 自定义字段（字段名可改），角色定位（主角/配角/反派/龙套）与标签；
- **关系图**：拖人物节点四向锚点到另一人物建关系（输标签如 师徒/宿敌）；点选关系线改标签/线型/颜色；悬停高亮一度关系网；角色·标签筛选；孤岛提示；◯ 圆形 / ▦ 网格排布；右键节点发送为大纲引用卡 / 打开详情；连线粗细跟随画布设置。

## 7. 设 · 设定 与 8. 灵 · 灵感

- **设定**：幕布式统一节点树（无限层级、图片、关系链接），世界观/力量体系/地理皆宜；
  - **关联关系**：条目右键「设置关系…」把两个条目（设定↔设定、设定↔人物）用带类型的关系连起来；拥有关联关系的条目**行尾出现关系卡片**，**悬停**看具体关系（类型 · 目标 · 描述），点击卡片管理；
  - **双击条目进入设定详情页**：面包屑路径 + 关联关系列表 + **可拖动关系图谱** + 子条目树（详见 §9.2 / §9.3）；
- **灵感**：片段收集箱，按时间排列，好点子可发展为设定或大纲节点。

## 9. 关系链接系统

「关系链接」含两条腿：**文内关系链接**（把某段文字指向另一个条目，原「双链」，机制与数据标记不变）与**条目级关联关系**（把两个条目用带类型的关系连起来）。

### 9.1 文内关系链接

- 正文/幕布/小传/灵感中：**选中文字 → 右键 → 添加关系链接…** 或手输 `[[标题]]`；
- 画布上关系链接显示为卫星令牌，点击跳转目标（章节/人物/设定节点等）；
- **悬浮预览窗**：悬停关系链接 / 令牌即在旁展示目标内容（带出现/消失过渡动画）；**按住标题栏可拖动**——拖离即「钉住」为常驻预览窗（悬停其他关系链接时原位换内容，不随鼠标移开消失，点 × 或 Esc 关闭）；停靠位置在会话内记忆（后续浮窗停在上次拖放处），**双击标题恢复跟随鼠标**；
- **与批注的区别**（两者可叠在同一段文字上，互不覆盖）：

| | 下划线形态 | 颜色 | 交互 |
|---|---|---|---|
| 关系链接 | 点状线，紧贴文字 | 主题色（随皮肤） | 悬停出预览浮窗，点击/跳转目标 |
| 批注 | 实线（2px），偏下 5px，带同色淡底 | 批注色（按用途可改） | 在右侧批注栏查看 / 编辑 / 删除 |

### 9.2 条目级关联关系（设定 ↔ 设定 / 设定 ↔ 人物）

- **设置**：设定条目右键「设置关系…」（或点击行尾关系卡片）打开**关联关系面板**——搜索目标（设定 / 人物）、选类型（位于 / 属于 / 控制 / 影响 / 关联，可自定义 + 反向名）、填描述（如「大陆东南沿海」）→「添加」即生效；面板可拖动，已有关系逐条列出、行尾 × 即删；
- **展示**：拥有关联关系的设定条目在**行尾出现关系卡片**（彩色胶囊：类型 + 计数，如 `位于 +1`），**鼠标悬停**即弹出具体关系列表（类型胶囊 · 方向 →/← · 目标名 · 描述）；
- **双向**：关系单向存储、双向展示——人物详情「关联关系」区同样可见并可从人物侧建立（如 人物「属于」某地点 ↔ 地点侧显示反向名「成员」），双向都可点击跳转；
- 关系随备份迁移；条目**彻底删除**（回收站清除）时其关系连带清理，仅软删（在回收站）时关系保留待还原。

### 9.3 设定详情页

- **双击设定条目**（幕布行或左侧节点树）进入**设定详情页**：顶部面包屑路径（点击祖先逐级切换）、条目标题与标签卡片；
- **关联关系**列表：类型胶囊 + 目标 + 描述，点击行跳转（设定 → 切换详情页；人物 → 跳人物模块），行尾 ↗ 跳到条目原位置；
- **关系图谱**：中心 = 当前条目，周围是一度邻居，连线标注关系类型（带方向箭头）；邻居节点**可拖动**调整布局（按条目分别记忆，重开保持），点击邻居切换到它的详情页；「适应」回到全览；悬停节点 / 连线与上方列表联动高亮；
- **子条目**：整棵子树按缩进列出，点击逐级下钻；「幕布中定位」关闭页面并在编辑器闪烁定位；`Esc` 或「返回」退出。

## 10. 正文导出详解

入口：⚙ 设置 → 数据 → **导出正文（选章节 · TXT/MD/Word）…**

| 选中范围 | 导出行为 |
|---|---|
| **1 章** | 直接以 `章节名.格式` 导出 |
| **多章（≤阈值，默认 30）** | **逐章分批**：仅首次确认导出位置，之后自动按顺序写入同目录，每章一个文件（章节名命名）；首步取消即中止。整卷/全选但章节数未超阈值时同样走此路径 |
| **超过阈值** | 弹出导出方式选择：<br>① **合并为单个文件**（按顺序合并，书名命名）<br>② **按章打包 zip**（每章一个文件，`序号-章节名`、按卷分目录，`书名-N章.zip`） |

- 格式三选：**TXT 纯文本 / Markdown / Word (docx)**；docx 保留加粗/斜体/下划线/删除线/字色、标题样式、对齐、列表与引用缩进；
- **阈值可调**：批量选择区数字控件直接改（2–500），即改即存。

## 11. 全局工具 · 设置面板

顶栏 **⚙ 设置** 入口是低频操作的统一入口（书架页与作品内均有；原版工坊与引力 / 琉光为面板，赤月戏为独立设置窗口），分五区：

- **外观**
  - **皮肤**：原版工坊 / 引力书舱 / 琉光画境 / 赤月戏 四选一，点击即换；原版工坊下另有 **宣纸 / 羊皮纸 / 暗夜书房** 三套主题（导航底部 ☀/🌙 也可快速昼夜切换）；
  - **中文字体**：思源宋体 / 霞鹜文楷 / 京华老宋体 / 朝华标题 / 云游手书 / 系统黑体；
  - **西文字体**：跟随中文 / Playfair Display / Montenegrin Gothic One；
  - **正文字号**：A－ / A＋ 在 13–24px 间调节；
  - 中英文分离：`--editor-font = 西文栈 + 中文栈`，拉丁字符（英文/数字）落西文字体、汉字落中文字体；**书架封面书名与作者圆印同步跟随**中文字体。所有字体均为随包本地字体（OFL 授权，GB2312 子集化），**不联网、不下载**；选择自动记忆，换机后随备份恢复。
- **模型设置**：多供应商预设（名称 / Base URL / API 格式 / API Key）、模型列表（拉取 / 手动添加 / 启停 / 点选使用）、温度 / 隐私模式 / 自动记忆；改动即时保存。
- **知识库模型**：语义检索开关与向量模型独立成页；向量模型走当前供应商预设的 Base URL 与 API Key，Anthropic Messages 格式不支持 embeddings。修改后在下一次语义检索或知识库构建时生效。
- **数据**：导入作品… / 导出正文（TXT / MD / Word）… / 备份全部数据（JSON）/ 恢复备份（JSON）… / 回收站 / 存储位置
- **关于**：写作统计（字数曲线按日 + 章节分布图表）/ 帮助与键位手册（本手册）

其余全局工具：

- **搜索**（🔍 / Ctrl+Shift+F）：跨全书搜索，命中选段定位；
- **回收站**：删除的章节/人物/片段恢复或彻底删除（彻底删除不可恢复）；
- **书签**：章节快捷收藏夹；
- **拆窗 ⧉**：大纲/人物等模块拆为独立窗口（边看大纲边写正文），窗口内可切换条目；
- **沉浸**：专注写作模式。
- **阅读**（仅正文页）：巨排章号 + 宽栏只读版式——收起两侧与工具条，章号/章题随正文滚动，底右实时字数；左侧目录细边条点击滑出章节列表（选章即切、自动收起），Esc 先关抽屉再退出；只读预览（可选中/复制），退出后恢复编辑。

## 12. 键位详解

### 全局

| 键 | 功能 |
|---|---|
| `Ctrl+Shift+F` | 全局搜索 |
| `Esc` | 关闭搜索/弹窗/画布右键菜单/连线编辑浮层 |

### 正文编辑器

| 键 | 功能 |
|---|---|
| `Ctrl+Z / Ctrl+Y` | 撤销 / 重做（编辑器内） |
| `Ctrl+S` | 手动保存（平时自动保存，此键兜底） |
| 选中文字 + 右键 | 剪切/复制/粘贴 + **添加关系链接** |

### 大纲画布

| 键 | 功能 |
|---|---|
| `Delete / Backspace` | 删除选中模块（容器连子模块，输入态不劫持） |
| `Ctrl+Z / Ctrl+Y` | 画布撤销 / 重做（↶ ↷ 同） |
| `Ctrl+K` | 画布搜索并定位节点（自动进入父层） |
| `Esc` | 关闭搜索 / 抽屉 / 右键菜单 / 连线编辑 |
| 双击模块 | 打开设置抽屉；行内编辑用右键「编辑内容」（`Ctrl+Enter` 提交，`Esc` 取消） |
| 方向键 | 移动选中模块（`Shift` 加速为 24px） |

### 幕布大纲（文本视图）

| 键 | 功能 |
|---|---|
| `Enter` | 新建同级节点 |
| `Shift+Enter` | 节点内换行 |
| `Tab / Shift+Tab` | 缩进 / 升级（子级 ⇄ 同级） |
| `Backspace`（行首） | 删除节点并并入上一行 |
| `Alt+↑ / Alt+↓` | 上移 / 下移节点 |
| `Ctrl+Z / Ctrl+Y`（`Ctrl+Shift+Z`） | 撤销 / 重做 |
| `Ctrl+B` | 加粗 |

### 人物关系图

| 键 | 功能 |
|---|---|
| `Delete / Backspace` | 删除选中人物（软删，回收站可恢复） |
| 双击节点 | 打开人物详情 |

### 搜索弹窗

| 键 | 功能 |
|---|---|
| `Enter` | 执行搜索 |

## 13. 常见问题

| 现象 | 处理 |
|---|---|
| 打不开 / DatabaseClosedError | 同数据目录已有实例在运行，关旧窗口再开 |
| dev 报 5173 端口占用 | `npm run stop` 一键清理（含 vite 残留） |
| 误删章节/人物 | 回收站恢复 |
| 画布连线绕远 | 连线严格使用建立时端口；删除重建即改用就近端口 |
| 换电脑 | ⚙ 设置 → 数据 → 备份（JSON）→ 新机「恢复备份」 |
| 导出时批量选择区没出现 | 仅在选中章节数超过阈值（默认 30）时出现；未超阈值的多章（含整卷/全选）默认逐章导出 |
| npm run dev 与 npm start 书不同 | 设计如此：调试版数据已隔离 |
